## 共同验收结论与反馈

**功能结论：** 待共同验收 / 核心功能可接受 / 有问题需修复 / 需再试玩（由用户选择，不按勾选数量自动认定）。

**体验优化（与功能缺陷分开）：** 地图是否拥挤或空、路线差别能否理解、文字是否清楚、动画快慢、刷单和换车节奏、最想先改的三点。可写“功能通过，但希望……”；有主观建议不自动等于功能失败。

助手负责的确定性证据包括：原始道路全程≤10km、路线去重、餐损固定抽样与折扣、评价合并与上下限、超时只扣一次、出发等级收入、跨日计数、旧档迁移、保存失败与备份恢复、重复结算保护。用户不必用反复抽样或改写存档证明这些规则；用户负责填写实际看见、按下与体验到的结果。

第一阶段没有骑手经营、站点升级、新城市、保温玩法或广告SDK。本期10条普通订单都能正常接；未来“首条高价远程易损广告单＋9条普通单”仅为后续方案，不要求现在能看广告。不以没有这些后续系统判失败。

真机加载、低端帧率、双指和系统后台需要物理设备另测。3秒/30fps是目标，不是既得结果；没有可靠数据就保留未测。完成桌面清单不自动表示发行通道或真机性能已验收。
