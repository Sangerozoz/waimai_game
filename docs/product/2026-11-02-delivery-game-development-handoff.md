## 4. 核心连接约定

- 每张订单只有一个ID与完成结果；本批状态、NPC工作、任务状态、钱/经验/库存/额度由同一经济事实推进，不让UI动画重复发奖。
- NPC用真实时间与剩余额度，主角用行程游戏钟；点击/阅读/后台不能被混成NPC加速或离线补跑主角。
- 购物成功先确认旧收益区间、余额、实例与资格，再一次提交新资产/费用/任务奖；交付单同理唯一提交收入、经验、完成量、额度。
- 任务只读取地图/车辆/招募定义，不另造价格；补给物品使用同一恢复动作，费用源区分金币/奖励库存。
- 主角活动批次锁定当前车；NPC调整等当前单结束后完成，不用重置订单换取新费率。
- 保存失败不展示已永久到账；给重试并保留现场。旧档真实版本需开发核对，不在产品文件擅自写入用户数据。
