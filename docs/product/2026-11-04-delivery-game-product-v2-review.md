## 1. 产品定位与完整循环

竖屏都市外卖模拟经营：亲自送单赚钱，选择购买骑手、车辆、地图或升级已有资产，组建配送团队，逐步发展到更大的城市。

**用户明确的变化：** 人物、车辆、地图均只需金币购买，不再要求等级、完成单数、持有指定车型或先买前一张地图。提高购买和升级成本，前期易起步，后期逐步增加投入，为以后新增地图和车辆留出空间。

**PM建议：** 保留“亲送体验＋团队经营”双循环；广告提供可选加速。长期目标靠资产选择、逐步增加的价格与更多内容支撑。所有现有商品从一开始即可浏览，价格和属性清楚展示。金币够便可购买，不通过隐藏资格再次设门槛。

普通配送：容量内组单→选择路线→取送与补给→逐单入账→整批汇总。
成长投资：收入→招募/配车/升级/买地图→提高生产能力与内容选择→继续经营。
广告选择：单次广告接专送，或单次广告开启主角10分钟自动配送；两种权益分别获得。

## 2. 开局、骑手与地图

**PM建议保留开局：** 100金币、评价80、体力100、主角和一台基础车；基础地图免费。主角靠实际亲送经验升级，金币不直接购买主角等级。最多30名NPC，加主角31人。

取消“地图开放NPC名额”与按序招募限制。30名NPC全部可见、可单独购买；每人限招一次，均需另配车辆。原来的2/4/6/8/10人可保留为人物故事与列表分组，不再构成购买资格。暂沿用同一NPC培养规则，不增加职业树或人物随机抽取。

## 3. 车辆：取消品级，保留性能与独立升级

**用户明确：** 取消车辆等级及固定等级称呼，同时保留车辆升级费用设计；灰、蓝、紫、橙、红、金、水晶等方向用于视觉差异。

**PM建议解释：** 删除D/C/B/A/S等车型品级；保留每台车的数字升级进度1—30，称“强化等级”，不再将数字升级与车型品级混为一谈。颜色属于车型外观主题，可有多个同色车型，不标“金色级”等稀有度，不把七种颜色做成必须逐级购买的链条。是否采用“强化”一词待审阅。

高价车不能只有换色；速度、容量、收入能力、适用路线必须有实质差异。同价位新增车可提供不同取舍，避免后续只能不断追加更高档。暂不新增耐久、维修、燃料或电池系统。

每台车独立购买、配备和升级；一车只给一人。商城购买不自动换装，配置车辆内管理实例。全部车型可重复购买，删除旧S/SS/SSS购买数量限制；已拥有数量与空闲数量明确显示。

候选升级：每车1—30；累计升级费 `U(L)=round(6P×((L−1)/29)^2.2)`，P为该车型基础购买价，单次报价取相邻累计费用差。1→30总费用为6P。候选满级效果为速度+25%、容量+40%、收入系数+20%，中间线性增长；容量按实际精度校验，显示精度避免误导。基础属性逐车另行出参数表，不能以定位文字代替已完成配置。

## 4. 骑手招募与培养

**PM候选价格：** 按人物固定定价，编号n为人物目录ID而非实际购买顺序，`R(n)=100×round(8×1.20^(n−1))`，n=1…30。约从800金币到158,300金币；选谁先买均不改变别人价格。现阶段基础能力沿用V1，贵的人物主要作为长期收集目标；若要赋予不同能力，需先补人物差异设计，不能暗示现已具有特殊技能。

NPC仍1—30级，以金币“升级骑手”。候选累计培养费 `C(n,L)=round(4R(n)×((L−1)/29)^2)`；满级总投入4倍招募费。满级收入+20%、固定作业耗时−15%，沿用V1效果，避免与车辆速度重复加成。

贵骑手的回本可能更慢，应明确展示培养收益，首页推荐目标优先帮助玩家组建第一支能工作的车队。不给贵人物虚构经济优势；该定价结构需在经济推演中重点审查。

## 5. 普通订单与专送订单

普通订单保留容量组批规则，没有固定三单上限；出发后不加单。系统提供快捷/均衡/平稳路线、逐单预计时间与风险；不可达和超载不能出发。取餐主动点操作、送达自动交付，逐单唯一入账，整批不重复奖励。

**用户明确专送口径：** 打开抢单大厅时80%概率看到一个专送候选，不是列表里80%都是专送，也不是每条订单各抽80%。每单约100—150金币，接取需要看广告；一次只配送这一单，不能与普通单组批。

**PM建议补齐流程：**

- 用一次有效候选会话保存80%抽取结果；同一会话反复进出、滚动、广告失败均不重抽。候选会话建议5现实分钟到期，到期后的下一次打开才新抽；在途批次不因此重建。
- 专送报酬100—150金币为候选标示基础配送费，初版全地图一致，不再乘车辆、主角或NPC收入倍率；实际迟到/餐损沿V1保留比例，接取前说明可能扣减，避免把标价误当保底收入。
- 专送重量不超过当前车辆容量，路线必须可达；不生成玩家不能接取的广告单。
- 已选普通单时，点专送先明确提示替换选择，用户确认后才播放广告；取消确认保留原选择。广告成功前不丢失普通已选单；成功后一次性提交专送批次，禁止再加普通单。
- 广告失败/取消不接单、不扣金币，候选保留。成功权益绑定该订单，重入或重试不重复要求看广告；主动取消该专送后权益结束，下一单另看广告。
- 专送只由主角配送；实际完成给正常10经验和一次亲送额度，不因专送价格高增加经验或额度。

专送较高收益是广告激励，仍需根据真实配送时长比较每分钟收入，不能仅凭100—150认定经济平衡。

## 6. 广告10分钟自动配送

**用户明确：** 看广告获得10分钟系统自动接单、选路、配送，完成后继续下一单，到时结束。

**PM建议采用以下统一规则：**

- 对象是主角。无活动批次时开启，广告成功后开始600秒可用时长；首页显示剩余时间和停止入口。与NPC自动经营分别计时。
- 自动只接普通单，不自动触发专送广告；根据实际容量组批，选择预计净收益合理且迟到风险可接受的均衡路线。到店自动取餐、自动前往下一站、自动送达，无需玩家点操作。
- 自动期间主角使用正常道路速度和服务时间，不使用点击加速，不绕过体力、天气与餐损。经验及亲送补额度只按真实完成的主角订单计算一次。
- 只统计前台实际自动运行时间；后台暂停计时和主角行程，回到前台恢复；已获得权益及剩余秒数保存。主动停止可暂停并保留剩余时间。有剩余权益时不再播放续时广告，不叠加多个10分钟。
- 体力低时优先使用可用库存，是否允许自动花金币由开启时的开关决定，默认关闭；开启后玩家设置总预算并可见剩余额度。无库存/预算不足则暂停并提示，不擅自购买，不自动耗掉整段权益做免费休息。
- 剩余时间不足以完成预计批次时不接新批次；预测误差导致到时仍在途，则停止接新单并免费自动完成该批后结束。该规则须结合真实批次耗时评估是否产生过长尾单。
- 每批实际送达即结算；结束反馈汇总单数、收入、补给支出、净赚和时长。广告取消/失败不给权益，回调重试不重复发放。

这是可选便利功能，不自动给NPC补满额度，也不将10分钟直接兑换成一笔固定金币。

## 7. NPC经营额度与亲送价值

保留V1在线/离线共用额度池、逐单真实结算、无额度暂停并保留进度。亲送仍是主角经验和团队经营额度的来源，NPC自己的单不循环补额度。

**需要覆盖的V1关联：** 买高价地图不再自动提高额度上限或每单补充量，避免“买图即扩大整队收益”与取消资格后的早买地图形成过强叠加。

**PM建议改为团队真实完成单数里程碑自动提升：**

| 全队累计实际完成单 | 额度上限 | 每完成一单主角配送补充 |
| --- | ---: | ---: |
| 0—59 | 15分钟 | 1分钟 |
| 60—239 | 20分钟 | 2分钟 |
| 240—699 | 25分钟 | 2分钟 |
| 700及以上 | 30分钟 | 3分钟 |

该里程碑只增强经营能力，不限制任何商品购买。主角手动普通单、手动专送、广告自动实际完成的普通单都补额度；取消、任务奖、广告观看本身均不补。30人并行收入与广告自动补额度的组合必须纳入经济测算。

## 8. 经济结构与成长节奏

以上价格均为**候选起点**，未完成模拟或实测。V1的旧车型倍率、NPC周期和地图价格不能直接与本表拼接上线。

普通订单候选基础报酬按当前地图为10/14/19/25/32金币，再乘实际车辆收入系数、主角经验或NPC培养系数及结果保留比例。NPC沿用同图普通报酬口径、独立周期结算；候选基础工作周期建议沿用V1公式起步，待新车基础速度确定后统一计算。专送按第5节独立标价，不叠乘上述倍率。

为避免倍率随新内容无限膨胀，候选十车型基础收入系数暂限定1.0—2.5，新增车优先通过容量、速度与用途区分。高价地图收益只渐进提高，同时增加地图内容和普通组单机会，不因购图价格高就按价格倍数放大收入。

候选体验目标：

| 阶段 | 希望玩家感受到的进展 |
| --- | --- |
| 首次15—30分钟 | 至少一次有感投资：新车、升级或向首位NPC积累；具体取决于接单方式 |
| 前1—3小时 | 逐步获得首名NPC与配车，形成亲送带动团队的循环 |
| 中期 | 招新人、改善车队、买新地图之间有选择，避免固定购买清单 |
| 长期 | 高价地图、收藏车与全队培养持续消耗金币，后续能增加同价位与更高价内容 |

这些是设计目标，不是由当前候选表推导出的可达时长；长期具体天数待用户审阅方向和收益推演后再定。不能通过人为拉长每一单等待来实现长期目标。

下一轮参数收口必须覆盖：无广告亲送、专送为主、10分钟自动、满30人团队、混合玩法、集中刷取六种场景。每种列出实际分钟产出、补给净支出、额度供需、购买时间与回本时间。当前专送、车队并行和价格之间仍有待验证的量级风险，不宣称已平衡。

成长任务保留实际购买后一次领奖，取消所有购买资格检查和资格文案。建议删除按消费额返10%的统一首购奖励，改为预先展示的少量固定金币或补给，避免高价新内容带来巨额返利；具体奖励表另审。普通配送收入、专送、NPC、任务分别记账；广告自动收入属于主角普通配送，加自动来源标记，不重复计算总收入。

## 9. 保留的配送体验与保障

体力0原地停止，吃喝或免费休息恢复；便宜补给后期持续提供。暂沿用V1补给价格/恢复量/耗时，不随资产售价同比涨价。NPC不需逐人喂养。

天气、餐损、超时保留V1的低风险起步与逐次结算原则，风险按当前地图确定；迟到仍送完，不重复扣款。后台冻结主角行程，NPC只结算真实额度内的时间。

取消本批全部未完成单，已送收入与经验保留，未送无奖，无额外扣钱和评价，已用补给不退。已入账不因整批汇总再发一次。

购买/广告权益/订单/经验/额度均有唯一结果，失败不宣称成功，重复回调不重复奖励。旧档人物、车辆、升级、已购地图和金币全部保留；旧车品级改为车型展示，不能删除玩家资产或按新价追扣差额。具体迁移由开发另出方案。
