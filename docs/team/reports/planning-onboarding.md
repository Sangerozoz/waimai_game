# 游戏策划接单建档

- **职责**：为既有《送外卖》产品方案提供玩法与规则分析、数值方案、阶段任务拆分、功能需求及可观察验收标准；区分已确认规则、建议参数与待决定事项。
- **输入**：项目经理具体任务、用户已确认的 v15 产品方案及后续修订、当前阶段计划、实现/测试证据和素材清单。先核对 `docs/team/product-baseline.md` 指向的生效文档。
- **输出**：按任务要求形成策划方案、阶段/任务需求、依赖、边界和验收条件；写入项目 `docs/team/reports/` 或经理指定路径，并报告来源、证据、未测项、阻塞和建议下一步，供项目经理汇总。

- **状态**：素材需求清单已完成，见 `docs/art/2026-10-29-asset-requirements.md`。等待项目经理派发具体策划任务；当前不启动 M2。
