## 对产品的理解

- 定位：点击即玩的外卖模拟经营、轻策略与收集游戏。使用Cocos，主体验是二维真实路网、虚构地名、车辆沿道路自动移动；局部立体展示服务于素材和成长表现。
- V2目标循环：查看大厅 → 接1–3单 → 预览路线/时限/载重/体力/补给 → 安排停靠顺序 → 自动行驶并可点击加速 → 到点取餐/交付/补给 → 逐单结算并继续余单 → 成长与经营。M2仍限单单，M3才开放三单，体力在M4接入。
- 策略来源：路线、时限、损坏风险、逐段载重、顺路组合、体力与补给的取舍。不点也能完成；同计划点击快进不改变游戏到达结果、收入、体力或风险，只缩短现实等待。超时仍能完成，保留零钱零体力的免费恢复路径。
- 成长层次：县城主动配送 → 骑手/站点/城市经营 → 省会与一线的波浪难度 → 国际、隐藏车/骑手、特殊大单与收藏/SSS强化。十档资产与五地区不是七个实施阶段的另一种叫法。
- 长期约束：车辆无损耗维修、骑手无工资；本地存档可靠；钱/评价/经验及各类等级概念分开；隐藏线索车与骑手分开；未实现功能不展示假收益。

## 实施与审查的关键约束

- 订单、行程、地点动作分开；后台冻结，停靠与服务边界不能被高倍速跨过。现实在线时间、玩家游戏时间和动画表现时间分别处理。
- 接取/撤回不免费换候选；线索仅首次真实交付发放。收入、动作、补给、存档重试不重复生效，旧活动沿用旧规则完成后再切V2。
- NPC按真实时间和费率分段，不追溯新增资产、不补发封顶截额；离线先整体截8小时再分段，500单总限一次。强化报价排除临时换车/降评价套利。
- 审查已关闭八项设计问题；这不等于对应未来代码已经修复。报告顶部更新注明易碎餐生成偏差已由M1代码修正，正文“待修”是历史记录。
- M1保留现有运行规则收尾。新时钟、点击参数、三单与补给按M2–M4引入，不把未来候选数值直接塞进当前验收。已有视觉授权继续作为表现约束。
