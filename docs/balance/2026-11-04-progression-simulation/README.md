# 完整成长路径推演与校准参数

这是独立设计模型，不导入游戏、不读取存档、不启动游戏测试。

## 文件入口

- `calibrated-parameters.json`：本轮最新候选，覆盖上一轮静态候选报价。
- `simulate.py`：离散订单事件、实际消费、车队额度、每日会话与有限离线收益。
- `simulation-results.json`：10种完整路径，每条150次会话，固定随机种子23。
- `sensitivity.py` / `sensitivity-results.json`：10组随机种子/广告时长/道路耗时敏感性路径。
- `session_checks.py` / `session-results.json`：短时登录、长时游玩与连续游玩补充。
- `verify.py`：前10/15单、合法容量、额度/离线与资金守恒核对。
- `baseline-120-sessions.json` 与 `intermediate-calibration-results.json`：历史校准证据，不是最新结果。

## 模型口径与局限

1. 首15单推荐路线不额外消费，普通单20/新车24，经验正常记录，收入等级加成第16单启用。广告路径允许提前买。
2. 以合法整数订单重量抽批；首单从能装下的订单取样，后续过重则该批不追加。策略估算与运行用同一重量分布。
3. 所有车辆保留，旧车可免费转交；一台车只给一人，买新车和升级均真实扣费。没有免费赠送第二台车。
4. 主角实际完成单才补额度；NPC只消耗同一个时间池，额度满时新增补时溢出，额度0停工。离线不补新额度。
5. NPC在主角广告/规划期间仍可工作，但只消耗现有额度；广告观看不另送金币、经验或时长。
6. 自动600秒归零后停止自动操作，模拟玩家接管余单，之后才可再开广告；没有无限免费自动尾批，模型并非无人值守挂机。
7. 自动补给假设玩家预先授权且预算足够；模型选择3金币恢复70体力，3秒服务；无钱可免费休息。正式流程仍须提供开关、预算与暂停提示。
8. NPC/主角均逐单入账，地图与改装仅改变下一批报价/时长，不追溯旧单；离线前后最终余额分开报告。
9. 道路秒数和订单供给为设计假设，不来自真实地图测时；天气/迟到/餐损用平均保留比例估算，未重现全部随机事件和具体路线。
10. 购买策略为边际产出/投入的启发式，不是数学全局最优；策略差异、随机种子和道路变化均单列，不把单条路径当所有玩家。
11. `fullyDeveloped`在会话结束检查，精度为一场会话；30NPC与满培养满改装是不同节点。
12. 有限内容目标完成后余额仍会积累，本稿不声称形成无限长期金币回收，也不通过删金币/强制工资/衰减处理。

## 复现

```sh
python3 docs/balance/2026-11-04-progression-simulation/simulate.py 150
python3 docs/balance/2026-11-04-progression-simulation/sensitivity.py
python3 docs/balance/2026-11-04-progression-simulation/session_checks.py
python3 docs/balance/2026-11-04-progression-simulation/verify.py
```

这里的150是单条路径的会话数，不是150次独立玩家实验。
