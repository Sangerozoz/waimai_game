# 数值平衡第一轮

目标：以当前真实整数格容量、升级费用、订单差价和有限NPC额度，验证前期购车/招人/训练节奏及策略取舍，不把公式正确或单元测试通过视作平衡。

- 开发A复用既有会话，在`a/`独占可复跑模型/报告，只读生产参数及领域源。本批先20/60分钟、无广告、常规/慢操作及至少4种投资路径，原始事件完整归档。
- PM在`pm/`做当前纯报价/边际成长核对，先查保护退出与报价阶跃等可复算问题；不与A抢文件。
- 开发B保持原隔离UI复验，不中断其原planned测试档；其真实单程收入、耗能和时长作为后续锚点，不冒充全玩家统计。
- 生产价格表、实际金币/资产/存档不因规划运行而改变。候选最多先改3处，必须有前后对照和既有进度/已签合同兼容方案，再统一审核实施。

沿用的设计边界：推荐正常路径10单首车、15单首NPC；20分钟3NPC与二八为需要重新验证的目标，而不是预设输出。自由购买、真实扣款、无强制广告、整数容量有实际用处。不得通过补贴或抬收藏尾价伪造达标。

本阶段运行的是真实领域函数/明确假设下的隔离规划，不是实测游玩或长期平衡验收。地图制作和真实用户存档不在写集内。
