## 平滑曲线及积分

目标倍率 T 和实际倍率 A 分开保存为临时内存状态。目标基础 1、上限 10/3，每有效击 +0.5，目标按真实秒衰减 1.5；任意连续一秒最多接受 8 击。点击只改变 T，A 在点击瞬间不跳变。

实际倍率遵循一阶响应 `dA/dt=(T−A)/τ`，首版 `τ=0.25s`。每帧按输入时间戳切段，并在目标衰减到 1 的位置再切段。任一长度 d 的区间内 `T(t)=T0+s·t`，斜率 s 为 −1.5 或 0，其解析解及积分为：

```text
C = A0 − T0 + s·τ
A(d) = T0 + s·(d−τ) + C·exp(−d/τ)
I(d) = T0·d + s·(d²/2−τ·d) + C·τ·(1−exp(−d/τ))
```

代码使用 `-Math.expm1(-d/τ)` 计算最后一项，减少短区间的相减误差；实际倍率限制在 [1,10/3]。目标回到 1 后，实际倍率沿指数曲线趋近 1。安全边界可直接复位，不保留余速。

同帧各段积分相加，以 `I/dt` 作为平均倍率传入已有 `OrderBook.advance`，同份积分推进行驶 elapsed、车辆位置和游戏行程剩余时间；不是帧末倍率乘 dt，也不是仅缓动车图。到站仍由 `advanceHandoff` 截断，剩余帧不越过取餐、去配送等人工确认边界。原 B3 的 3.33 秒候选计算不适用于此次曲线及新节奏，不作为交付承诺。
