## 玩家可见结果

- 大厅与当前单共享紧凑布局：期限；食品图、名称份数及重量/特性；右侧黄色费用与公里数；左右取送地址；可选备注。普通单黄“抢单”、转单绿“接受转单”。真实三路线横排，普通备注单在标准/短屏及安全区不需滚动；异常超长原文保留并允许中区滚动。
- 规划、去店途中、到店待取餐都可点击较小红色“取消订单”，不扣钱或评价、不重抽候选、不改变刷新额度。途中取消保持实际停靠点；重开和下一单沿合法道路从该点继续。点击“取餐”开始服务后不可取消。X仅收卡，中央“订单”可找回。
- 新单链路：去取餐 → 到店停住 → 取餐 → 2秒取餐服务 → 停住等待去送餐 → 配送 → 自动按已有要求交付并结算。大dt不能跨过手动边界，服务进度可恢复。
- 到店、取餐完成和结算会从收卡、车辆、地图或账单查看状态主动触达；同次事件不每帧抢弹，同一候选取消后重接属于新尝试，可再次提示。旧活动保留旧自动进度，未回答的旧交付要求也不再弹询问，已完成回执与奖励不重写。
- 结算按内容自动收高，只保留本单实际收益、事实状态、存在时的晚到/餐损收益影响，以及评价和一次经验。收入公式与实际入账不变；对照金额仅解释影响，不再扣一次。X/遮罩清理已完成单并回首页，继续接单才打开大厅。
- 规划卡展开时临时隐藏站点与定位控件，为路线留可读空间；收卡或出发后恢复。保留底栏与中央订单入口。

## 本轮发现并关闭

1. 单行路途中取消后，刷新候选生成忽略实际锚点，可能生成身后不可达商家。现生成、预览和接取都以真实点合法接入路网；原反例及修复回归保留在核心审核。
2. 普通备注单短屏路线底行被裁。现移除重复装饰文字、按真实内容测量紧凑行高和地图留白；模块与真实三路线图及零滚动测量通过。
3. 同ID取消后重接沿用旧事件键，吞掉第二次到店提示。新接单尝试在实际accept后清理呈现键；独立内存旧逻辑红灯/当前绿灯及开发回归均保留。
