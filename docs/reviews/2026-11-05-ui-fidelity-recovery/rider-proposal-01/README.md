已体现：我→主角；等级变小紧贴姓名；未招募放肖像下；统一收益加成（不再写基础），所有NPC均显示；作业耗时改取送省时；招募按钮仅招募且费用单列；顶部骑手标题删除，车辆/地图/账单的标题也纳入删除要求。

旧“作业耗时100%”指固定取/送服务基准，97%即同类操作比基准少约3%，不是骑行速度或整单期限。因此确认稿改用取送省时0%/3%。未招募以当前初始培养等级展示真实固有收益+0～24%及省时0%，不伪装已经培养。现有身份与原生肖像不重绘。

金额示例逐项按用户指定：39,140→约4万；42,170→约4.5万；3,080,000→308万。前两例并非同一种普通四舍五入规则的自然结果，当前仅是确认稿的示例映射，不能悄悄当作统一算法上线。精确扣款仍是39,140、42,170等原值；近似标价用约，确认购买应明确实际扣款，避免价格误导。

1万以上其他数值使用万单位的范围已登记；应用到余额、收入、费用等时，要区分缩写与近似展示，仍待本稿确认后收口规则。本文不据图宣布任何价格/逻辑变动已获用户批准。

用户后续订单/地图/账单要求同时登记：去订单地址条末端pin；重量紧跟餐名；订单金额用货币符号而非金币图片；修时间图标与字的垂直对齐；地图未购买改未解锁但不恢复购买资格；账单金额前金币图标全部去掉。专送是已生成候选而非可用接单链路，真实广告SDK缺失仍是阻塞，不能假广告成功。
