# M1美术建议

- 定位直接用现有3D target原图（圆蓝底、白边），只去宿主方底；原生准星仅作加载失败回退。
- 金额与评分统一字号、行高、字重；评分改爱心。建议原生画饱满圆润心形，顶部左侧白色短高光，蓝白描边/浅阴影；缩小时轮廓仍须一眼可辨，不能像水滴或星形。
- station沿用原图并放大至普通底栏图标的可见尺寸，保持灰度禁用。底栏铺满可用宽度及手势区，用浅暖白半透明原生圆角底板，轻蓝灰边/柔影；层级在地图上、图标下，图标文字保持整体，中央黄色餐袋突出。不要拉伸图集PNG。
- 车辆投影置于车图下、道路上：低透明中性蓝灰软椭圆，模糊边缘、轻微偏下，光向遵循左上主光；随车节点同步位置、旋转/缩放校准，切车和加载失败仅留一个影子，不改原图。
