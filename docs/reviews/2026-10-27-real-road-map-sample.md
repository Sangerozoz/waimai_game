| 检查 | 结果 |

## 浏览器实测

在内置浏览器操作构建产物，常规页面约 439×767 CSS 像素。另检查 393×852 的设备模拟比例；浏览器页面缩放为 110%，其实际布局约 357×774 CSS 像素，保留相同的长竖屏比例。浏览器检查不等同于手机真机性能或双指手感。

- 切换主干道、平稳路：高亮路径、卡片、出发按钮同步变化。
- 放大、缩小、全景、路线视角、骑手定位：实际操作有对应结果。
- 拖动：首次实测发现异常，已定位为 Creator 的 loose spread 转换将 Map 迭代器错误当成数组。复现时拖动后偏移不变并抛 TypeError；改用 `Array.from`，重建后同一拖动检查通过，偏移从 `[-29.22,-19.74]` 变为 `[87.60,-119.87]`。
- 暂停：暂停时累计时间为 0.2 秒，间隔多次操作后仍为 0.2 秒；定位及恢复继续有效。
- 到达与下一单：平稳路线累计 24.8935 秒后到达送点，骑手与终点坐标一致；完成数从 0 变为 1，点击「体验下一单」后进入第二单，配送进度归零。第二单约 14.4941 秒后送达。
- 长竖屏：顶部和底部保持可见，额外约 281 个设计像素用于地图。配送中调整模拟尺寸后，状态和计时保留，仍可送达。原始页面截图证实完整占屏；设备模拟时默认缩略截图存在额外缩放，因此采用 CDP 原始页面截图留证。
- 重看路线：点击「再看路线」后状态恢复选路、计时归零、骑手回到取餐点；手动换单可轮换到第三组再回第一组。
- 最终构建浏览器错误检查：重建后无新增 error 记录。Map 迭代器异常在修复前被明确复现，未混记为最终通过。
- 临时输入追踪通过页面重载清除，不写入产品代码。
