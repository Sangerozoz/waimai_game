# 阶段一第二轮用户验收返修

2026-10-28。用户逐项反馈16组功能：13组明确通过，地图边缘/区域分布、真实取送的到店停顿、结算回执的蒙层三组要求调整。[原意记录](stage-one-feedback/user-feedback.md)。早前17/3/4属于历史轮次，保留不混算。

## 改动

- **点位留白：** 营业区内缩从150米加至450米；普通地图只显示内部选中的40家商家、120个顾客。160点中城区80、郊区48、偏远32，距可玩边界最近453.30米。保留原310个地点索引和坐标，供旧活动与回执恢复。
- **区域派单：** 真实建筑300米格中≥10栋归城区、3–9栋归郊区、其余归偏远；在城区长轴两端且跨度超过55%的完整取送（含骑手取餐起点）归为跨城。订单目标城区50%、郊区30%、偏远15%、跨城5%，每批至少5条城区、最多3条郊区、2条偏远和1条跨城；连续20个新增名额最多1个跨城名额。区域不满足附近道路时长时优先补城区，不强凑远单。保留每批至少8条≤20分钟、全部≤30分钟，以及目的地优先不重复的规则。
- **内容轮换：** 缩小区域后增加最近两批大厅目的地避重历史，仍只在手动刷新成功时扣额度；候选生成先搜索新目的地，再允许稀疏范围回退。
- **到店停顿：** 新接单增加独立可选字段`pickupWaitElapsed`，到商家后真实等待2秒，显示“取餐中”；首单已在商家也先取餐。停顿不增加道路展示分钟、行驶动画或晚到判定。停顿中重载继续剩余时间，不重抽餐损。大帧时间按到店、等待、继续行驶分配，不跳过应消费的2秒。
- **结算蒙层：** 实际Graphics填充用`#00000099`（黑色alpha153，60%），不再靠褐色加UIOpacity。弹窗卡片保持不透明，阻挡输入与触摸关闭保持。

## 兼容

PlaceCatalog按原实现重建v1和v2地点池以计算可信旧地图身份，新增v3只追加新地址并选择营业点，不移动历史地址。新身份包含营业区及营业点选择，防止仅改变派单政策却未迁移候选。旧普通候选确定性筛选补齐，不消耗业务随机源、每日额度或经营资金。旧活动缺少停顿字段时继续原时钟、路线、餐损与回执；新接单使用2秒停顿。

修改前真实运行生成v3 idle/routes/running/done及310地点的[基线夹具](../../delivery-game/tests/fixtures/feedback-v3-baseline.json)。迁移与二次恢复核对活动、经营、骑手和回执完整保留。新增大厅历史字段可选且有范围校验。
