# M1 按压反馈规格

适用 `SampleUI.ts` 的 `tap` 与 `button`；命中根节点及 UITransform 尺寸、scale 恒定。只缩放/调亮视觉子树（皮肤与标签同一反馈组），按下即时至 0.96，释放后约 120ms 回到 1；缓动先快后柔。可用轻微变暗替代缩放，但不改变布局/命中。

每个根节点仅接受一个主触点：首个有效 touchId 开始按压；额外手指忽略，不接管、不触发。移出起点7 UI像素阈值（与现有 ScrollView 一致）即取消按压；之后即使移回也不恢复本次点击。TOUCH_CANCEL、禁用或节点销毁立即还原视觉并清空触点；禁用时不注册/执行回调。正常 TOUCH_END 先清状态并开始短促恢复，再同步执行一次回调，不等待动画。取消/拖动不回调。连续点击重置视觉过渡，从当前值平滑压至0.96；旧恢复不得覆盖新触点状态。动作结算完全由回调/业务状态驱动，禁止依赖动画完成。
