# M1美术诊断

已用view_image查看首页截图、ui-chrome及ui-icons，核对manifest与两份皮肤源码；未操作游戏。

- 顶部外框、蓝底与信息框重复叠层。PNG自带白厚边、蓝内沿；paintBox另绘倒角，skin成功仍留宿主Graphics，应只留一套正式背景及独立信息层。
- 底栏长蓝胶囊是chrome；招募、车辆、地图、账单PNG各自也有蓝圆底白边。可等比放大复用图标，删除整条底座及额外入口板，文字叠在图标内部下方，禁用态保留灰度。
- 定位外正方框属宿主，target PNG另带蓝圆底白边；仅删方框不够，应改用已有原生准星。关闭可复用close图标。
- 紫面板原为近方形。resizeCartoonChrome虽用SLICED，却保留源尺寸再非等比缩节点，标题及宽窄黄按钮仍压扁边角。标题、手机机壳/屏幕/顶部、按钮宜按目标尺寸原生绘制；九宫格须固定角区、取消整体非等比缩放并验证最小尺寸。
- 头像、金币、星和入口插画可复用；chrome限原比例或验证后的九宫格。本轮无必须新图缺口。弹窗未提供截图，判断依据源码，需修后多尺寸截图验收。
