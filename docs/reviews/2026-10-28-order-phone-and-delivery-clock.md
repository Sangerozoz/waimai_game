`bash scripts/build-map-sample.sh`：退出码 0，Cocos 3.8.8 构建完成，约 3 秒，最终日志 `/tmp/delivery-map-r2-build.log`。

实际浏览器操作结果：

1. 黄色待命界面出现「接单」，点击打开有外框、状态栏及五条订单的模拟手机；关闭按钮、翻页、重新打开均可用。重开后页码、订单 ID 与骑手位置保持。
2. 列表接单后手机收起，进入真实路线选择；接单前维持 idle 状态，骑手不移动。
3. 实测一单显示 63 分钟、动画 10.5 秒。出发 follow=true，暂停后两套时钟保持；拖动解除跟随，定位恢复，继续后沿路送达。
4. 最终构建初始页实测显示 13/23/34/42/83 分钟，对应动画约 2.17/3.83/5.67/7/12 秒。接下 83 分钟的订单，实际动画累计到 12 秒即到达，完成数为 1，仍保持跟随。
5. 点击「继续接单」回到手机，保留已送达的骑手节点，列表继续可选单。改变至长手机比例后，当前页码、订单 ID、骑手节点和完成数保持。
6. 地图缩放、全景、路线视角及手动查看继续可用。最终浏览器 error 记录为空，原始结果见 `map-sample-r2/browser-errors.json`。

常规内置浏览器约 439×767 CSS 像素。另使用 393×852 设备比例（浏览器页面缩放会影响实际 CSS 尺寸），保存原始页面截图；已恢复常规视口。图片在 `docs/reviews/map-sample-r2/`：`yellow-map.png`、`order-phone.png`、`route-choice.png`、`arrived.png`、`portrait-phone.png`。
