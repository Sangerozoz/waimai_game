# 立体控件美术参数

统一左上主光；主蓝#2878EB、亮边#FFFFFF、浅蓝过渡#6EA8ED、黄#FFD23F/金边#B87513、关闭红#DE4258、禁用灰#AAA69C。以目标尺寸原生绘制：外沿厚约2px，白色上沿高光1–2px，下沿金/深色压边2px并配低透明短阴影；圆角随控件高度取约0.35倍。文字与图标置于表面上层，按压只压缩内层。窄刷新、宽接单、圆形X共用同一厚度和光向，按宽高调圆角，不缩放PNG；只绘一套材质，勿与旧皮肤叠加。

复核截图：底座和黄按钮的亮边、下沿厚度与圆角协调，文字未被压住；红X同为亮面圆角塑料，但相较黄按钮高光略强、阴影略重。整体已经统一，可仅微调关闭按钮高光/投影至同等克制。
