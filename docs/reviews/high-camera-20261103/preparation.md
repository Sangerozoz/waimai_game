# 高斜俯视技术准备（仅文档）

2026-11-03，固定开发。依据：[用户确认与PM首样参数](../../art/2026-11-03-map-production-method-review/high-camera-confirmation.md)、[长期实施基准](../../product/implementation-baseline.md)。本文件是后续接入的技术约定建议，不是实施完成报告。

用户确认60–65°固定视线对地面俯角，通常6–10m退距、控制楼高、骑手沿道路中央；接受少量局部穿帮。不需要自由旋转、逐栋拆建、动态真实光照。62.5°和首样临街10–12m是PM制作参数。当前只准备定义与数据需求；不改源码、构建、部署、原路网、边界、存档或既有素材，不运行tests/typecheck/回归/渲染矩阵/页面。

## 1. 正交投影定义

沿用地图平面坐标x/y，物体离地高度z（米）；地图原点O=(ox,oy)，dx=x-ox、dy=y-oy。固定水平朝向45°，画布像素向右/向下，θ为视线相对地平面的夹角。每个投影单位的像素数P，镜头平移(tx,ty)：

```text
X = ( 1/√2, sinθ/√2)
Y = (-1/√2, sinθ/√2)
Z = (     0,   -cosθ)

sx = tx + P × (dx - dy) / √2
sy = ty + P × ((dx + dy) × sinθ / √2 - z × cosθ)
```

这些是同一个正交相机下世界单位轴的投影，地面X/Y投影长度不必为1，不能分别重新归一化。落地道路和路线使用z=0；楼高用于遮挡估算/标注，完整建筑PNG不能再按z重复上移一次。Cocos向上Y转换统一在显示适配位置执行，不能让道路、车、静态图片分别猜符号。

62.5°取值：sinθ≈0.8870108332，cosθ≈0.4617486132；X≈(0.7071067812,0.6272113751)，Y≈(-0.7071067812,0.6272113751)，Z≈(0,-0.4617486132)。地图轴的屏幕斜率为±sinθ，轴线角为±atan(sinθ)≈±41.5734°，不是±62.5°，也不是tanθ。

| 视线俯角θ | 屏幕地面轴线角 | 楼高10m的地面等效遮挡延伸 | 楼高12m的地面等效遮挡延伸 |
| --- | --- | --- | --- |
| 60° | 40.8934° | 5.774m | 6.928m |
| 62.5° | 41.5734° | 5.206m | 6.247m |
| 65° | 42.1863° | 4.663m | 5.596m |

表为三角函数制作计算，不是游戏/页面测试。等效遮挡延伸是H×cotθ，解释见第3节。历史`.866/.5`是旧画面约定，不等同这里的正交基；旧“30°”命名不能作新俯角标定，旧PNG不能通过旋转、翻图、压扁替代高俯角原生素材。

## 2. 原路网、静态美术与动态车共用的数据

建议把坐标与投影约定集中在一个module的interface，由地面、路线、骑手、标记共同调用；只在Cocos显示适配的seam转换Y方向。当前不实施该module、不为它预建复杂可替换系统。

| 数据所属 | 必需字段/事实 | 用途与约束 |
| --- | --- | --- |
| 场景投影 | projectionId/version、模式orthographic、elevationDeg=62.5、azimuthDeg=45、axisX/axisY/axisZ、pixelsPerUnit、originMap、canvasYDown | 数值与轴必须一致；P是统一世界单位投影比例，不是每张图各自的缩放 |
| 镜头 | focusMap、screenOffset、viewport参考尺寸、zoom/屏幕像素比例 | 原地图位置不改；新机位可以另设显示取景，不能盲搬旧fit比例当作同一屏幕几何 |
| 原道路 | sourceCitySHA、roadId、完整原节点、width、原连接/方向 | 原线与宽度不挪，铺装围绕原线绘制；不把AI画的道路反向覆盖源路 |
| 静态整景/地块图 | imageFile/SHA、nativeSize、projectionId、覆盖map bounds/polygon、图中控制点pixelUV↔map、绘制道路路缘/中心线参考 | 整景至少提供分布开的3个以上地面对应点来暴露误差；图片与地图需可核对，不凭目测平移一个点宣称全图对齐 |
| 独立建筑/树 | nativeSize、原图落地anchorUV、groundPolygon或真实占地候选、displayWidth/尺度、heightMeters、树冠地面投影范围、projectionId | 整图保持原生宽高比；地面轮廓和机位另行实际读图，不凭prompt认定标定精确 |
| 建筑入口 | 可见入口entranceUV、frontage.normalMap；隐藏门用明确entranceMapOffset、visible=false | 门点与道路方向对应；隐藏门不伪造可见UV；入口路面连接不等于自动改变业务取送地址 |
| 退距与高度 | 逐实例wallFootprint、nearestRoadId、carriagewayEdgeSetbackMeters、heightMeters、参数来源与candidate状态 | 退距从车行道路缘到外墙，不从中心线/屋檐/图边计算；无确切高度时明确候选 |
| 动态骑手 | 原map位置、roadId/原节点段+t、方向、wheelContactAnchorUV、nativeSize、显示画布宽/屏幕目标、opaqueBoundsUV、projectionId | 原路中线位置通过同一投影显示，阴影与标记共锚；不通过屏幕直线插值偷换地图路线 |
| 遮挡制作参考 | cameraGroundDirection、静态楼/树的占地与高度候选、道路中心线可见带及端点/路口/停车位 | 用于局部布景预留，不等于预建全面切片或逐像素遮挡系统 |

地面控制点只可用于检查同机位素材的统一比例与平移；若角度/局部道路偏差明显，应反馈重绘或改地块图，不能用非均匀拉伸/透视变形硬压到路线。地块拼接还需一致P、接缝坐标及重叠留边；留边范围不进入经营边界定义。

当前PM的一张完整街角构图是观感候选，没有上述原路对应关系时不作原坐标资产包。即使它看起来满足62.5°，也不等于动态车可沿其画中道路准确行驶。

## 3. 用楼高与退距保留车道

本基下，朝相机的地面方向u=(1,1)/√2投影到屏幕下方。楼顶相对脚点向屏幕上方移动H×cosθ，在地面等效为沿-u延伸H×cotθ；这是视线遮挡范围，不是太阳投影。固定光影可另烘焙/画入地面，不需要动态真实光照。

对候选楼的完整wallFootprint F，可把`F沿-u扫掠长度L=H×cotθ`作为几何遮挡估算。前景楼可能盖住其远侧道路；后景楼并不因同样高度必然盖前景路。树冠、屋檐、招牌和素材画法偏差需额外余量，不能只看楼根点。

对局部直路，令n为外墙指向道路的单位法向，k=max(0,n·(-u))，则朝车道的法向延伸候选为L×k；不应对所有道路方向套同一个H×cotθ全额值。若外墙至车行道路缘退距d、道路宽W，中心线离墙约d+W/2。可见中心带半宽r及附加余量m满足下式时，可作为这一段直墙/直路的保守筛选：

```text
H × cotθ × k + r + m < d + W/2
```

这只是局部几何筛选，不包含复杂转角、悬挑、树冠和完整PNG的非几何外沿，不是“完美避开”的保证。62.5°、H=12m时L≈6.247m：d=6m可能轻微压到路缘（最不利k=1），但W=8m的中心距为10m，未加骑手/树冠余量前约剩3.753m；d=10m则更宽裕。狭路、转角、高楼或近景树冠需要单独收口。不能据这个例子声称旧8栋或整县均满足6–10m。

放大后的骑手是一张有头身高度和宽度的图片，因此真正要保留的是“沿原中线移动时整张可见骑手轮廓”的屏幕通道。后续资产准备时，应以轮点锚点+不透明外沿形成移动包络，并与楼/树的实际屏幕轮廓对照；不只让轮点落在一条可见细线上。此处记录制作方法，本轮不运行渲染矩阵或页面检查。

布景优先级：近路放10–12m低楼、控制屋檐/树冠越界；不满足时先降低候选楼高/体量，或只在授权地块内调整候选美术摆位。保留人行道、入口与树池，不靠空白铺装或大草色掩盖场景不完整。始终保留源道路和经营边界；若真实地块容不下退距，记录具体roadId/placement和冲突，不偷偷挪路。路口、弯道、取送停车位置沿用原合法坐标，若目标不在中线不能擅改业务地址，需后续具体任务界定局部显示/连接方式。

## 4. 保留“骑手至少2倍”要求

旧engine-v3参考：R01原生画布显示宽3.2m、P=32，初始scale=0.6129619059310744；原屏幕画布宽约62.7673px。MC-REV1已写6.4m，在同镜头下约125.5346px，原图轮接地锚点不变。这是参考画幅的画布宽，手机CSS尺寸还受视口适配影响；不透明车身大小与画布留白不同。

新高俯角改变地面投影，不应靠新楼图包围盒自动fit来确定骑手可读性，也不能只复制旧fixedScale就宣称道路画面不变。后续应同时记录统一场景P/zoom和骑手最小屏幕目标：在同参考画幅下，旧同图画布至少125.5346px；换高俯角新图时，还须按opaqueBoundsUV使实际人物/车身轮廓不小于旧可见轮廓的2倍，避免新图留白抵消放大。6.4m是表现画布宽，不是车的真实碰撞尺寸/属性。

骑手和接地影继续共用真实轮点锚点及地图位置，不因放大而偏离中线。现有NE单帧不是62.5°动态车资产包：保留身份和源文件，待具体派工生产/选择匹配新机位方向帧；不水平翻图或平面旋转伪造俯角，也不自行启动生图。沿路中央是显示/场景约束，不擅改正式路线连通、交通通行方向或蓝框限制。
