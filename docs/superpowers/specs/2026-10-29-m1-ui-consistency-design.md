来源：2026-10-29用户最新五项反馈。项目经理在既有授权内安排实施，不展开M2或重新选择风格。覆盖前轮相关边距/扁平按钮/浅色底栏呈现，其他功能和结算链路保留。

## 本轮明确结果

1. 顶部个人信息横向展开：以游戏实际可见画面为基准，左右安全区以内各留12 CSS px。转换SHOW_ALL缩放后再布局；避免Header宽度之外又加inner padding，造成可见信息再次向中间缩。身份/余额/评分分布占满可用宽度，正常与长金额均完整，金额评分继续同号同字重，爱心保留。
2. 站点图标右侧可见边缘距离安全右边12 CSS px；初始化、资源加载后、更新页头、保存刷新和重建保持一致。使用图像实际等比尺寸/边界核对，不能只量100宽宿主。站点仍放大、灰度禁用。
3. 圆形3D定位图标相对本轮前实际尺寸放大1.5倍（当前scale1.4→2.1等比例），保留原图，不增加方形底板。点击范围随之容纳完整图标；右边、底栏及地图署名保持可达和安全距离，失败准星回退继续存在。
4. 底栏保持通栏，使用黄色主色、圆润立体塑料质感：上沿浅色高光、清楚厚度、下沿金色压边/阴影。图标/文字仍在上层，中央餐袋突出，覆盖手势安全区。几何按实际尺寸绘制，不拉伸旧PNG。
5. 弹窗普通操作、手机列表接单/刷新、关闭按钮统一圆润立体语言、相同光向和边框比例，包含正常/禁用/按压状态。主操作为黄、次操作可蓝、关闭红色X，但材质与造型一致。关闭保持图标，不回退文字。窄刷新、宽接单、圆关闭均不可压扁、双重叠皮或吞掉文字；按压只作用视觉层，命中根稳定。

## 技术与验证边界

优先共享小型主题绘制辅助函数，让底栏和按钮共享色彩/厚度/高光原则；只在目标按钮和底座使用，不给所有面板/经验条/地图自动加多层背景。几何多层用于一个自洽立体Surface，不回到宿主+PNG两套皮肤叠画。

保留前轮结算X/遮罩回idle首页、继续接单打开大厅、关闭大厅无卡片、按压/滚动/缓存/异步关闭保护、圆形3D定位、爱心、站点禁用、车辆单投影。业务经济/订单/时钟/存档不改。

开发是源码唯一写入者，美术提供配色/厚度短建议，测试独立复核。以真实Cocos生产组件隔离渲染验证标准720×1280、360×560、长金额与有左右/底部安全区的边界；量取CSS缩放后的顶部和站点12px（允许栅格/透明边缘约1px误差），定位尺寸相对基准1.5倍。拍首页、车辆/地图/账单、手机刷新/关闭/接单、结算按钮、宽窄按钮和按下状态。技术检查和静态渲染不替代用户真机体验。

不接触用户现有页存档或自动操作其真实业务；继续使用内存隔离fixture，Storage被拦截的引擎探测如实记录。交付 `docs/reviews/m1-ui-consistency/`：修前快照、实际布局测量、截图、精确diff、测试/typecheck/build日志及报告。只为真实边距/缩放/触控行为加有意义检查，纯颜色用图验，不写源码匹配测试。
