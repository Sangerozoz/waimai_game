# 阶段一第二轮用户验收返修

用户已逐项反馈16组功能，其中13组明确通过；地图边缘/区域分布、到店停顿、回执蒙层三组需返修。已通过的附近时长、缩放、列表、内容、选路、取送、动画行驶速度、交付、评价、成长、车辆、刷新、保存和布局规则继续保留。页面仍由用户验收。

- 普通营业点位边界留白由150米加到450米。保留原地点的索引与坐标供旧档履约；正常地图只展示选中的内部营业点。
- 根据真实建筑在300米格内的密度划分：≥10栋为城区，3–9栋为郊区，0–2栋为偏远；大跨度跨越城区两端的取送归为跨城区。正常选用40商家/120顾客，城区点约50%、郊区30%、偏远20%。
- 派单目标城区50%、郊区30%、偏远15%、跨城区5%；每批至少5条城区单，跨城最多1条，连续20个新增名额最多1个跨城名额。区域不可达或时长不合规时优先补城区，不强行拉长路线。保留每批至少8条≤20分钟，全部≤30分钟的规则和目的地优先不重复。
