# 地图载具顶视图接入

用户明确要求先把不同等级载具的顶视图应用到地图。沿用素材库已确认的车型顺序和用途，不调整车辆经营规则。

- D/D+/C/C+/B/B+/A/S/SS/SSS依次对应旧电动车、翻新电动车、品牌电动车、长续航电动车、大箱摩托车、运动摩托车、豪华摩托车、限量豪华摩托车、黄金限量摩托车、至尊飞行摩托车。
- 原始透明PNG逐字节复制到工程资源，按当前车辆惰性加载；本期D与D+可实际使用，其余只登记素材映射，不开放新档位。
- 地图标记替换为等比例40×64设计像素图片，固定屏幕尺寸、不随地图缩放放大。素材车头朝上，贴图局部旋转−90度，让地图0度向东的道路角与车头一致。
- 首次打开、存档恢复、升级及布局重建都同步当前车辆。图片加载期间保留原图标，失败时回退；过期异步回调和已销毁节点不能覆盖新车辆。
- 类型映射和图片加载封装在独立模块，CityMap负责位置与道路方向，MapSample负责把玩家车辆档位交给地图。
- 仅检查代码、资源、方向和异步切换；不操作浏览器。用户检查当前车图、升级后换图与道路转向。
