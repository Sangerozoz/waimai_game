# 导航与账单

用户已明确布局：站点移到地图右上角，底部从左到右为招募、车辆、抢单、地图、账单。站点仍未上线，只有灰色图标/名称，无说明、无点击；底栏保持无背景，抢单黄底大字。

账单12项：今日收入、今日订单数、今日好评、钱包余额、在线时长、配送里程、准时率、超时、差评、累计配送费、累计完成订单、单日最高订单数。采用两列六行弹窗，无多余提示。

- 今日按设备本地自然日，订单归属结算日；今日订单数为完成单数。收入/累计费使用实际到账配送费，不含初始资金，不因买车减少。钱包读当前现金，累计完成订单沿用现有真实总数。
- 今日好评按单笔评价变化>0、差评<0统计，中性不计；准时/超时依据本单lateSeconds，与路线名称无关。准时率=当日准时完成数/当日完成数，0单显示“—”。
- 在线时长是实际前台时长，含待命/选择/配送，不含后台或关闭；跨本地午夜分段。配送里程是当天已完成订单的真实取餐+送餐路程，取消不计。
- 每天仅保存汇总，不保存无限增长的逐单历史；结算时原子登记，不重复记账；订单/资金仍由OrderBook持有。存档增加可选billing，新档从零准确记录，旧档保留全部原进度。
- 旧档未记录的历史不可推算：保留真实累计订单与钱包；已有历史的费用/最高单日单数及迁移当天指标以≥显示已知下限，迁移当天准时率显示“—”。之后完整日期的每日数据正常显示；累计历史不伪造。
- 账单配送中可查看，配送不暂停；到达需求和结算优先。关闭、重开、窗口变化不修改收入或订单，在线时长正常累计。页面体验仍由用户检查，不自动操作浏览器。
