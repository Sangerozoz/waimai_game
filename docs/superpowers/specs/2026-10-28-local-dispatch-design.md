# 县城地图比例与附近派单修订

来源：用户在第一阶段试玩后要求默认50m、最大100m、最小30m；普通派单一般10km以内；骑手从当前地点去餐厅再送餐并留在终点；大厅10单、不翻页；高价远程易损置顶订单需广告，本期未接广告则只记后续方案。

## 本轮实施边界

- 地图比例尺固定60设计像素，对应默认50m，允许30–100m。滚轮、按钮、双指、选路视角、定位均不越界。原全城视角改为周边视角，范围100m，不再自动缩至公里级；长路线靠跟随和拖动查看。出发默认50m跟随。
- 大厅共10条普通订单，单列表上下滑动，无上一页/下一页。关闭再打开保持订单，不消耗刷新。送完按当前位置重新保留可达且全程≤10km的候选，补齐10条；已有范围内候选尽量保留。
- 本轮对10km采用保守口径：骑手当前位置→餐厅→客户的快捷道路总里程≤10000m，不能仅量直线或只看送餐一段。提供的其他路线也限制≤10km。优先附近餐厅，取消原11000m远途生成档。距离筛选不扣手动刷新次数。
- 骑手从当前点出发，依次经过餐厅和客户；取餐阶段、送餐阶段明确显示。到达、结算、下一单、取消选择和重载均不得将位置重设为初始餐厅。
- 当前存档键不变，数据版本升级至2；有效旧版30候选单迁移为10单，保留现金、评价、经验、车辆、骑手地点、每日次数、活动单与固定抽样。已接旧版远单继续履约，不撤单或重抽；后续新单执行10km规则。
- 黄色主题、结算、车辆、每日2次刷新、双时钟（30分钟约5秒、动画≤12秒）沿用。原Main.scene、DeliverySession.ts及其旧键不修改。

## 后续广告单（本期不实现）

未来大厅仍总共10单：第1条为1条高价、远程、易损的广告解锁特殊单，其余9条为普通附近订单。广告未成功前不可接单，取消/失败不占用当前配送；奖励回调幂等，解锁资格与接单原子保存，避免重复领单。远程距离、加价和易损概率在接入广告SDK时再由方案确定并验证可读性与收益。本期保留10条普通可接订单，不放不能完成的广告占位卡，不模拟看广告成功。

## 验收

1. 新开与出发显示50m，所有缩放入口限制30–100m。
2. 大厅10条可滚动到第10条，无翻页；点击和拖动不误接，打开/关闭不重抽。
3. 真实地图从多处终点连续派单，每条普通候选和可选路线的实际道路总长≤10km。
4. 两单以上沿路经过不同餐厅、送达不同客户，第二单首点等于第一单终点；途中、结算和闲置重载位置不倒退。
5. 旧30单存档迁移保留经营/车辆/刷新与活动配送结果；当前10单恢复不消耗随机数或重复发奖。
6. 自动检查、类型检查、构建与浏览器操作分别记录；真机未测明确标识。
