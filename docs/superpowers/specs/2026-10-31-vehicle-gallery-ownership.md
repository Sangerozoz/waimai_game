# 车辆宫格与拥有上限增量

来源：2026-10-31用户要求可查看全部车型、满足资格后允许重复购买；10名骑手各需独占一车，加主角需11辆。用户明确S最多4辆、SS最多3辆、SSS最多2辆。本增量覆盖V2第8节“车型最多11”中S/SS/SSS的统一上限，其他数值与阶段权限不变。

| 每款车型 | 拥有上限（含主角使用） |
| --- | ---: |
| D、D+、C、C+、B、B+、A | 各11 |
| S | 4 |
| SS | 3 |
| SSS | 2 |

上限按每款分别计算，非全车库合计；免费初始D也算一辆，不能通过购买再得到12辆D。已拥有车辆有独立稳定实例ID，一辆车不得同时由主角与骑手使用。未分配车辆可闲置。后续骑手人数与站点容量仍按原阶段规则，不因车库开放提前实现或解锁。

车辆入口采用独立车辆页面，全部车辆/我的车辆，两列宫格可纵向滚动；侧45图、名称/档位、速度/载重、价格及拥有数量，未开放型号可看具体条件。详情与购买确认可用弹窗。购买资格与余额/库存上限分别显示，满足资格才允许购买；不因点击购买自动满足条件。已解锁车型资格永久保留供副本使用，遵守原方案相应资格约束。

购车副本价格沿用原V2：D基础500元加目标档累计升档费；原车升档与新购是两个动作，不把升档价伪装成新车价。当前未实现地区/高级资格不能通过新UI伪装已实现。实际布局、存档迁移及分步边界见同日实施计划；本文件不代表代码已实现。

按用户节奏，阶段完成前不测试/typecheck/回归/游戏存档操作。存档版本迁移须保留已有车、余额、订单与未知未来版本保护，所有购买由业务层原子处理并正确处理保存失败。
