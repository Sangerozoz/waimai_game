# M1结算退出与美术跟进

用户2026-10-29在项目经理会话追加的明确要求。本次覆盖上轮定位准星、无底栏背景、金额大字号和五星评分的呈现，其他M1规则保持。

## 结算退出链路

- 配送结算右上角X：退出已经结算的订单展示状态并保存，关闭弹窗、回到完整默认首页。没有底部结算详情/继续接单卡片，不打开接单大厅。按通用弹窗约定允许遮罩关闭时，其结算语义一致。
- 「确认，继续接单」：退出同一展示状态并保存，打开接单大厅；关闭大厅回完整默认首页。
- 两条路径都不重复结算/入账，不清除历史账单，不改余额/经验/评分/骑手地点；重建、恢复和刷新后不能重新冒出已退出的结算卡或弹窗。内部销毁/切换弹窗不冒充用户确认，不递归触发退出。保留保存失败的可见提示与既有重试保护。

## 美术结果

1. 定位使用已有ui-icons中圆形3D target图标（含图像本身圆蓝底/白边），只移除宿主外部正方形底板；原生准星仅作加载失败回退。
2. 顶部金额和评分使用同一字号、行高和视觉字重，正常金额不再大号突出。长金额以正确计量/换行保障完整，保留已修复的Array.from构建边界和安全区。
3. 评分用爱心，取代五角星。沿用圆润材质与高光，爱心须可辨，不能用星形替代。优先代码原生圆润爱心，无位图需求时不启动生图。
4. 站点图标显著增大，与底栏普通入口的可见尺寸相近；站点当前未开放，继续灰度禁用，不伪造点击功能。文字与安全区不重叠。
5. 底部菜单增加横跨可用屏幕宽度的背景，延伸覆盖底部手势安全区。采用轻浅、稳定的原生底板，与现有蓝白/外卖黄协调；不重用拉伸PNG。五入口仍为大图标和内部下沿文字，中央餐袋更突出，保持按压与动作。
6. 地图车辆下方增加柔和、低透明的接地阴影，位于车辆后面/道路上面，随车辆移动，转向/缩放和切车不漂移、不重复叠加；不改变车辆原始图像、尺寸、路线、命中和配送速度。加载中或失败也保持合理单一投影。
