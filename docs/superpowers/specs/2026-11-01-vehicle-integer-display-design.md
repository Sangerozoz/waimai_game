# 车辆成长整数展示与10元基础配送费

2026-11-01。展示规则、基础费及高档车上限已由用户确认；车型基础值与成长/费用曲线仍为候选，未接入游戏。

> **同日人数纠正与新价：** 当前采用[30名骑手版联合定价v2](2026-11-01-vehicle-and-rider-pricing-v2-30-riders.md)，五图新增2/4/6/8/10名。下述300行属性合表同步使用新购置/升级费用，替代80人版价格与P=1000元示例；金钱价格直接为整数元，车辆属性仍按精确值计算。

## 1. 本轮确认

- S、SS、SSS分别限制拥有数量，每档上限均为实际已招募骑手人数加主角。
- 例如10名已招募骑手加主角，共11人，则S、SS、SSS各最多11辆；全部招满30名骑手后，各最多31辆。
- D至A不设购买数量上限；车型仍须已解锁且余额足够。
- 基础配送费采用10元，替代前版数值说明中的20元参考基数；距离、地图、加急等附加费用以后另定，不能自动沿用旧范围。
- 用户对精度问题已明确选择：仅显示整数，实际计算保留精度。保留原候选成长曲线，最终显示四舍五入，不因展示改动让实际属性出现平台或虚构增长。

## 2. 取整口径

- 速度和容量：从车型基础值与车辆等级计算实际属性，再四舍五入为整数展示。实际寻路/载重校验使用真实值，不从展示值反推。
- 收入和费用：内部金额按分计算和保存，完整结算公式最终取整到分；界面以元四舍五入展示。实际总额累积后再显示整数，不累加已取整的展示金额。
- 收入增长在面向玩家说明中使用整数参考金额或整数百分比，避免显示小数倍率；不能用已取整的倍率重新计算真实收入。
- 部分相邻等级的整数展示可能相同，但实际速度/容量仍逐级增加。升级界面不能虚构每级必定加1，也不以四舍五入后的差值作为真实升级增量。
- 购买和升级的余额检查、真实容量是否足够等按实际数值判断，避免只根据界面整数作业务判断。
