# 真实路网地图样板

用户已确认：采用地图经营游戏的二维风格，以真实道路数据为基础，所有游戏地名使用虚构名称。当前交付是可审阅地图与路线样板，验收后再接入完整配送经营。

## 本次交付

在现有 delivery-game Cocos 工程增加独立 MapSample 场景，保留原 Main 场景和存档。使用公开 OSM 小范围街区提取，保留道路与建筑几何、道路节点连接及通行方向，不发布真实地名。源数据和许可随样板保存，游戏通过本地数据运行，不依赖在线瓦片或实时导航。

画面为手机竖屏：深蓝顶部状态区、浅色大地图、清晰道路与建筑层级、底部白色订单与路线选择面板。提供全景、路线视角、缩放、拖动、定位及一单沿路配送演示。所有可见按钮必须有实际行为；没有接入的经营功能不设置假入口。

路网以原始 OSM 节点 ID 保持连通性，不通过线段几何相交自动连路。排除高速、楼梯及禁止通行路段；保留允许路线的方向。路线长度、耗时、演示位置使用同一份路径。三种选路偏好为快捷、主干道、平稳，完全重复的候选不伪装成不同路线。至少选出一组存在不同合理通路的演示起终点。

颠簸与速度是游戏配置，不能声称来自真实路况。样板的配送时间压缩、收入和风险仅用于演示，不改原游戏经济和存档规则。选中路径和移动位置在地图缩放后保持一致。

## 验证出口

- 数据真实可追溯，游戏地名均为虚构，原始来源与许可另行记录。
- 路线每一步在有效道路上、遵守定义的通行方向、不会从桥面直接跳到桥下。
- 近景和全景可读，地图不再局限于小插图；选路与移动实际可操作。
- Cocos 类型检查、地图算法检查、浏览器预览及截图检查完成；手机真机未测时明确标注。
- 交付地图样板，不宣称完整游戏或用户体验验收通过。
