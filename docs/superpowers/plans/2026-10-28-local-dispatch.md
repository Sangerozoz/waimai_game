# 县城附近订单与地图比例 Implementation Plan

> 执行方式：在现有codex/food-delivery工作目录内按顺序实现与验证。当前用户反馈已授权本轮修订，无需逐文件重复审批；第一阶段v1恢复快照保留。

**Goal:** 给玩家10条附近订单、可读的近景地图和连续移动的取送体验。

**Architecture:** OrderBook负责10单候选、按当前位置的距离约束及存档迁移；CityMap统一限制所有镜头比例；OrderPhone使用Cocos滚动视图展示单列表；MapSample展示当前取/送阶段。

**Tech Stack:** Cocos Creator3.8.8、TypeScript、Node行为检查、Web Mobile。
