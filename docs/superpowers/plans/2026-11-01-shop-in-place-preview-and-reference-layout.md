# 商城局部更新与效果稿布局收口

2026-11-01，用户再次提供商城完整效果图并指出四类偏差。主参考已存`docs/art/vehicle-shop-layout-final/user-target-reference.png`。本轮不再设计新排版，目标是还原已认可效果稿与正常选择行为。

## 已确认原因

- 余额固定左侧coin位置、金额在一段固定宽框里右对齐，二者自然产生大空白，未按金额实际内容宽定位。
- 上轮PM错误派成上下两行参数，目标实际是图标→标签→数值→单位同一行；本轮覆盖旧的上下行要求。
- 卡片tap调用openGarage，销毁整个gallery和ScrollView重新建，因此点击任意车型后回顶。这是选择更新范围错误，不是滚动本身应有行为。
- 状态文本仍套通用较大字号/较宽框；需要独立紧凑胶囊、细边和明显小于车型名的字号。
- 车辆在预览框中心，而场景接地区较低；按用户建议大预览下移约20 CSS px，保留原图比例及铭牌留空。

## 固定开发清单

- [ ] 余额：金额右端固定、按实际文字宽度计算金额左缘；金币中心放左缘前4–6 CSS px加自身半宽。数字变长金币向左，不以固定列隔开；长数字在可用余额区内适配，标题不被遮挡。使用已有币图，符号不重复。
- [ ] 参数：速度表图标、速度标签、12/26.4数值和km/h单位，同一水平行；包裹图标、载重标签、5/80数值和kg，同一行。两组用竖分隔，购买区独立。速度组允许比载重组更宽，空间不足统一等比例适配该局部组，不退回两行，也不把整段字符串缩得很小。
- [ ] 点击车型：保留gallery/ScrollView/content节点实例与现有偏移，只重绘固定尺寸上方预览子树并更新选中框；不调用openGarage。异步旧资源回调不能覆盖新预览，原tap拖动取消规则保留。
- [ ] 浏览中选择D→SSS或重复选择不改变滚动位置；筛选切换允许明确重建/回顶。购买确认返回若需刷新库存，尽量保同筛选偏移，不把无关全页重建作为预览更新。
- [ ] 未开放：明确的深灰紧凑胶囊、浅灰细线、两侧内留白，居中小号字、单行；车型名独立大一档。拥有状态同样有自己的内容框。局部字号跟卡片比例设置，不能通用m.aux导致三列粗大裸字。
- [ ] 车辆：大预览图片相对当前下移约20 CSS px，用cssUnits换算，不用20设计单位假充；车身不能压住铭牌/参数栏。以轮胎/支架可见接地点靠近地面，不按透明画布假底边；飞行车型可保本来造型。
- [ ] 继续D～C+炭灰、B～A蓝、S族橙金基础，SS/SSS精细色差仍待用户补图，不在本轮恢复旧纯灰或重生车辆。所有商城/骑手业务不变。

固定开发独占MapSample.ts商城相关代码，可拆局部预览组件/内容宽测量helper；不改全局readable、道路、经济、schema或用户存档。现有生产图复用，无需新生图。
