# 第一阶段收尾与用户验收交付计划

**授权：** 用户要求先完成第一阶段，再一起验收；提供测试用例，由用户验收功能并提出优化意见。继续沿用game-idea-to-plan，后续阶段与广告SDK不在本轮。

**目标：** 补齐全图实际场景细节，完成可运行交付及当前可执行的验证，给用户可勾选、可记录反馈的验收材料。

## 固定范围与选择

- 原真实路网、虚构标签、黄色主色、50m默认/30–100m、10条普通订单、实际道路全程≤10km、取送连续位置及双时钟保持。
- 外围地图优先补充真实OSM建筑、水系与绿地。大请求曾超时，改为分区请求、逐份完整XML校验后再集成；不添加未经说明的虚构几何伪装成真实数据。
- 采用单独的场景细节导入步骤，只更新buildings/areas/waterways，不改变nodes/roads/pois及保存图指纹，保护已有玩家进度。
- 建筑随镜头分块绘制并保持有界缓存；新增体量先实测加载与构建。如数据本身缺少建筑，明确保留真实空地而非乱填。
- 验收用例分正常功能、恢复/边界、可选手机项及体验建议。随机餐损不要求用户反复抽到，自动规则检查由助手负责；用户重点检查实际反馈是否清楚。
- 用户现有4179存档不清空。新档验收用独立本机端口的存储区；验收表自己的记录与游戏存档分开。
- 新开系统/广告/骑手/站点/城市暂不纳入。用户验收结论仍是待验收，不代替用户勾通过。
