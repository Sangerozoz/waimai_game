## 2. 当前事实与建议参数

修前事实：`FoodCatalog.ts`中耐放6种、普通5种、易碎5种；两生成入口按sequence轮换，易碎31.25%。本轮已改为集中抽样，目录属性不变，配置版本`county-food-mix-1`。

推荐只调整类别选择，并保持非易碎餐品的现有5:6相对权重：

| 类别 | 推荐权重 | 长期生成目标 | 说明 |
| --- | --- | --- | --- |
| fragile 易碎 | 11 | 10% | 沿用县城目标 |
| normal 普通 | 45 | 40.909…% | 在剩余90%中占5/11 |
| durable 耐放 | 54 | 49.090…% | 在剩余90%中占6/11 |

权重总110，不是额外消耗或车辆属性。该分配已应用于独立食物配置`county-food-mix-1`，不套用V2试算的时间/补给参数。

保持16种餐品、图片索引、名称、真实易损类型与单份重量。先抽类别，再在同类别中选餐品；绝不通过把蛋糕标成耐放来满足比例。单批优先不重复，在匹配池用尽时允许合法重复，不越过类别配额强塞新品。

首单保留原固定推荐餐品。统计分母只计新规则生成的非首单，不计已保存旧候选、不计预览/开关大厅、不用玩家挑选后的完成分布代替生成分布。

### M1-02：修正生成比例与餐品多样性

**前置：** M1-01基线和上述权重明确。

**文件：** 预计修改`delivery-game/assets/scripts/map-sample/FoodCatalog.ts`、`CountyConfig.ts`、`OrderBook.ts`；新增`delivery-game/tests/food-selection.test.cjs`，调整`city-content.test.cjs`与`scripts/test-map.cjs`。原餐图资源不改。

**建议接口：** 在现有食物模块集中实现纯选择规则，避免两个生成入口各复制一套权重。

```ts
// 只在真正创建新订单时调用；两个roll均为[0,1)内的独立有效样本。
selectFoodForOffer(classRoll:number,itemRoll:number,shownFoodIds:readonly string[]):FoodItem
```

**任务步骤：**

- [x] 先加入真实生成流缺口检查并观察现有31.25%不满足10%目标；不能仅对手写模拟分布做检查。
- [x] 配置类别权重，类别抽样与同类餐品选择分开；参数非法、正权重类别无餐品应明确失败，不进入无限重试。
- [x] 同类未显示餐品优先，池已用尽再复用；使用独立样本选类别/餐品，不用固定`sequence % pool.length`与固定类别周期叠加，避免某类永远只有同一道菜。
- [x] 两个实际生成入口都接同一规则，首单推荐保留；食品名称、图片、重量、fragility保持一致，份数与载重检查不放松。
- [x] 只影响真正新生成的单。`list/accept/cancel/serialize/restore`不调用重抽食物，原候选/活动结果不改；旧合法候选在自动补单时仍按原规则保留。
- [x] 去掉“每批至少9餐种、三批30单必须覆盖全部16餐种”的硬约束。这不是用户要求，若推广成每30单保证全16种就至少要5易碎/30=16.67%，与长期10%不相容。改验同类优先去重与足量生成后覆盖。

**必要检查：**

| 类别 | 输入/过程 | 应观察的结果 |
| --- | --- | --- |
| 区间边界 | classRoll为0、略低0.1、0.1、略低56/110、56/110、接近1 | 依次落在易碎/普通/耐放的正确区间 |
| 图片与类别 | 各类挑选首/末餐品，多次同类挑选直到用尽 | 实际餐品类别始终正确，未用尽前优先不重复，用尽可复用不卡住 |
| 非法配置/输入 | NaN、负数、越界样本、正权重空池 | 明确拒绝，不生成错餐或无限循环 |
| 长期分布 | 4个固定种子，每种至少10000次非首单选择 | 易碎10%±1.5个百分点，普通45/110和耐放54/110各±2.5个百分点；记录原始计数，不声称随机样本精确10% |
| 真实生成集成 | 注入测试日期/随机源的小路网，统计至少2000个新非首单；另验实际地图少量新批次 | 两入口确实使用新规则；集成易碎10%±3个百分点，真实地图的附近/城区/时长/容量规则不回退 |

频率样本在独立测试环境生成，不能耗用户刷新额度或改真实系统日期。测试选择规则时不计算重新打开和重复接取的已有订单。

**验收：** 类别目标、餐品真实属性与图片一致；旧候选/在途单不重抽；统计范围和样本量可追溯。短期多样性不再以提高易碎概率换取。
