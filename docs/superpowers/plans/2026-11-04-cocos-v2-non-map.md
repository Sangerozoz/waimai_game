# Cocos V2非地图逻辑接续计划

**Goal:** 在既有Creator 3.8.8工程中先实现最新二八版经济与非地图状态逻辑，保留旧档资产与原路网，地图素材独立继续。

**Architecture:** 复用既有domain/map-sample及单写者存档保护；经济模块版本化，广告以独立权益状态模块接入，不把SDK成功回调伪造成普通按钮。正式表现与旧存档适配按真实调用链推进。

**Tech Stack:** TypeScript、Cocos Creator 3.8.8、既有CJS行为测试约定。

## 全局约束

用户本轮允许业务开发，覆盖先等地图完成才做产品开发的旧顺序。仍未授权过程运行tests/typecheck/回归/游戏或读写实际存档，阶段完成后集中测试。本轮可编写待执行用例，不因技能默认TDD要求打断用户已定节奏。地图、美术、路由与在途未提交文件不清理、不覆盖。

模型分配：复杂存档/经济集成使用gpt-6.1-sol high；独立广告权益状态使用gpt-6.1-sol medium；资料由PM整理，不为简单整理再开Agent。禁止GPT-6-astra。Agent约20轮（不计工具调用）用精简交接文件换新会话，不fork长历史。
