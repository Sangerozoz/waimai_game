## 看图结论与边界

- A：整体暖光/河岸/生活细节成立，但建筑和车辆视角偏俯斜，街区偏古镇；NPC头像与主角相似，工作状态用了绿色。正式量产应保持真实顶视地图、角色身份区分和配送蓝色语义。不能把这张当新头像母版已接受。
- B：地图更接近用户第一参考的俯视道路，经营状态集中于下方，中央道路更清楚；NPC人物材质更接近第二参考。主角、NPC仍需单独人设母版检查，底栏/头像尺寸必须根据实际屏幕再设计。
- C：三单、三个目的地、各自倒计时、体力34/100、雨天及红灯提示、喝水1元/吃饭3元、点击加速可见；闲置五导航已隐藏。地图路径是示意，有路由连续性/道路贴合待真实数据重绘，信号灯装饰可能出现灯色混杂，不能认定逻辑正确。
- 所有画面的680余额、96评价、等级/体力/订单价均为概念样例，不来自用户存档；1/2表示第一图已招1名、可招2名，第二名报价110元来自30人价格候选。
- C中水1元/饭3元是总案新增的补给候选；用户只确认随时按钮补给，尚未接受具体价格、恢复量或耗时。
- 生成文字用于概念表达，正式金额/时间/标题应由引擎动态绘制，不从本图抠字或烘焙整屏。
- 建筑、道路、河流和车辆位置均是生成示意，不是现有OSM真地图；正式实现继续使用真实几何、顶视车辆、分层材质和可移动相机。
