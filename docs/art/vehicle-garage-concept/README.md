## 2026-11-01最新设计调整：商城与配车分开

用户认可v1画风，明确车辆页改为商城，只管车本身及购买；主角/其他骑手的配车统一在骑手页，已被其他人使用的具体车辆不可选，再购一台可供分配。本条覆盖下文v1“使用中/主角座驾”及车辆页配置入口的冲突描述。已用内置imagegen编辑生成`vehicle-shop-screen-v2.png`，提示词同名txt；v1保留。具体规则与现有实现边界见`docs/superpowers/specs/2026-11-01-vehicle-shop-and-assignment-design.md`。未改代码，骑手页未实现；商城不能抢占其他人车辆，购买不自动装备。v2拥有数量旁误放金币图标，独立皮肤与后续定稿应移除。

用户于2026-10-31明确授权从生图开始，先获得完整效果，再规划游戏实现所需素材、资源和动效；本轮没有授权直接把未确认方案写入游戏。用户此前已明确暂停零散界面修补，指出界面缺少游戏感，车辆页尤甚。

## 视觉提案与边界

骑手日常车库，左上暖光，旧橙色D车作为主角，下方收藏区首屏三列两行。该方案比原暖白面板更偏深炭灰、磨损金属，仅为车辆页候选气质，尚未被用户确认，也未扩展为全游戏规范。其他界面及地图不改；首页仍沿用用户选择的地图方向。

画面中的速度/载重为占位，余额/状态仅为构图样例；实际实现读取现有数据。六格仅示意首屏，十档车型和“我的”真实实例需保留。工具、停车框、备胎均是装饰，不开放维修等新玩法。没有改代码、构建、测试或操作用户玩法/存档。

## 推荐生产方向（待用户视觉确认）

为实现本图的材质和层次，推荐补制：一张无车/无UI/无字车库底图，以及一套无字UI皮肤（可装一张图集，共享普通/选中卡框、信息条/面板、按钮、页签/档位底板等组件）。车辆优先复用10张既有侧45；按需要整理透明边。引擎负责布局、文字数据、状态、交互与简单补间。接地影可用通用柔边图或引擎绘制；首版无独立前景、骨骼或序列帧的必要。

“只新增一张背景+普通代码组件”只能代表结构可运行的最低资产数量，不是还原该效果稿的品质承诺。若以代码绘制皮肤，也须等效呈现材质、边角和层次。不能再把能显示与能点击当作整屏视觉完成。
