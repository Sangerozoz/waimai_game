# 用户纠正：按完整区域整张生成，再拼接

2026-11-03，用户在R2地块出图中指出：

> 不对吧，我们还是沿用一栋建筑，一栋建筑去生成吗？
>
> 难道不应该是一次生成一个区域，一次生成一个区域拼接吗？

明确采用的主生产粒度是**一整片区域**：一次包含多个连续街区、多栋建筑、道路、人行道、绿地、树池、庭院与固定光影，随后按共同地图坐标与边缘连接拼成大地图。此前只把1–2栋楼和地面合成一个地块，粒度仍过细；不再以逐栋/一两栋地块持续生图、逐块摆放为主生产线。动态骑手和必要运行标记仍独立。

保留已基本满意的高机位画风、建筑适度更大、原路网/边界/骑手通道及少量穿帮容忍。先从原地图取一片有完整路口/多块场景的区域作原路底稿，整片生成，再用同尺度、同镜头、同光照与相邻边缘参考制作下一片；接缝点和路口对应需有实际证据，不能凭提示词称已经无缝或精确对齐。
