## 最新范围纠正已执行

产品方案与地图制作是独立两条线。本轮没有生成任何地图背景裁切/合成PNG，没有加入地图背景引用；需隔离的本轮地图衍生PNG清单为空。原有地图页与`mapPreview`调用保持。本轮不加工地图、不向地图线派工。

只读查看了既有独立产品素材`docs/art/vehicle-shop-production/garage-clean-background.png`：原生1374×1145，强暖黄夕照、较暗工位和竖向构图，与当前浅蓝白、日间中性宽幅车辆预览不符。因此**未裁切、未染色、未复制接入**，不把旧车库或空白UI底冒充合适新场景。U21保留**独立产品环境素材阻塞**。

## 本轮实际实现

`delivery-game/assets/scripts/map-sample/V2GameUI.ts:409`改为上方全宽车辆预览，下方名称、实际拥有数、新购等级、速度、容量、收入加成与唯一购买按钮。图片／参数／报价／购买目标继续来自同一个当前选中`v`，不改经济、资格或存档。

新增`VehicleShowcase.ts`及meta，仅创建中性浅色产品UI面、裁切框和加载失败提示，调用原`vehicleSideArt`；原车像素、身份、10档映射和比例不改。当前原生1536×1024仅等比缩小到378×252，不能称为新增高清素材。

顶部卡保留原顶缘、增高到444逻辑像素，预览660×268；宫格标题／视口顶部相应下移。三列、十档选择、卡高194／行距205、滚动key `vehicles`、底缘和滚动恢复机制保持。`V2ApprovedSkin.ts`未改；公共资源helper、公共manifest、原车图和地图页未改。
