## 样例与功能边界

- 六页使用同一[样例状态](sample-state.json)：680金币、体力78/100、评价96、主角Lv.5、骑手1/2、D车2辆/C车1辆。数字是概念样例，来自产品V1的配置与展示规则，不是玩家存档或游戏截图。
- 招募页主角当前C车Lv.5显示18km/h、11kg；商城展示新购C车Lv.1显示17km/h、10kg。这是车辆等级不同，不能把商城属性覆盖到主角当前车。
- 阿航为已招1名NPC，小夏尚未招募。小夏招募费110、一次奖励11；空闲D车只是库存提示，不代表招募自动配车。
- 自动经营12/15分钟是全队共享剩余额度，亲送完成一单补1分钟；不表示每人各有15分钟或充值能力。
- 抢单页4单重量2+2+2+3=9kg；显示容量11kg、内部实际11.2kg。单笔实际15.97、展示16，总实际63.88、展示64；实际容量/收入计算仍须使用产品参数精度。
- 账单按分记账、界面元取整。今日配送221.64、补给5、净赚216.64，界面分别222/5/217。累计余额为初始100+配送1133+任务57−支出610=680。
- 首页是空闲风格母版，没有展示成长目标卡、实际配送路线或活动骑手。完整状态页、展开列表、滚动/安全区、补给/暂停/结算等交互仍按产品V1后续实施，不能从六张静态图推断已全部设计或实现。
- 次页以同一街区质感作背景，生成的建筑与绿植细节存在差别；概念图不作为真实可移动地图或路网几何数据。实际按钮/字体/资产在引擎中独立实现，不能整屏贴图替代页面。
