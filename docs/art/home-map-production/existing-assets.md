## 结论与最小缺口

三张可复用为空地装饰房屋/院落，需按完整可见轮廓选位置，不覆盖真实道路、已有建筑、水域和取送保护区。三张均近顶视，仍有少量下缘墙/棚，不可宣称为严格无立面的通用屋顶。T03院落额外占地应计入放置保护框，不能只算屋顶。

真实不规则轮廓不能直接用完整房图贴满。可由开发将屋顶内部样本遮罩到原轮廓，女儿墙/外沿与统一右下投影按真实轮廓绘制。T01/T03瓦面具有主脊与光暗方向，不宜整屋平铺；T03候选rect仅为上部单坡瓦面。上表材质rect为保守观察候选，未裁原件、未验证无缝。

**建议仅补HB01-flat-roof：1张1024×1024不透明暖灰混凝土平屋顶材质，代表8×8m（128px/m）**。严格正交，无女儿墙/空调/风管/房屋边界/道路/字/强光斑，低反差、弱方向性、可平铺目标。原因是T02内部仍有接缝与设备投影，不是稳定无缝通用材质，任意真实轮廓覆盖大面积后易出现设备残片或重复墙体。最终无缝性待实际图观察，提示词不能替代实物结论。

**本轮无需再补HB02整套瓦顶模块**：T01与T03已覆盖矩形瓦顶与住宅院落，优先复用。瓦面局部样本只能作小范围候选，若后续确需大面积无缝瓦顶再单列缺口，不因这一局限重做全套。

尺度为制作建议而非测绘：T01约18×11m、T02约15×9m、T03含庭院约16×14m；以屋面设备约0.8–1.2m辅助校准。原图无测绘标尺，开发需与street-guide真实米制范围协调。图像旋转会同时旋转烘焙光影，避免任意旋转/镜像造成光源不统一，不能以保持图向为由改变真实轮廓。
