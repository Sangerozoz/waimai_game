# 路网与导航对齐小样

打开现有4186服务下的 `/delivery-kit/navigation-pilot/`。点路上起终点，或点示例，再播放。蓝色标记只沿绿色计算路径移动。左下错误车道已从路网剔除，底图画面本体暂未修。

Tiled文件为 `导航路网.tmj`。此文件是独立确认主路副本，未覆盖此前用户稿/助手稿。修改后网页不会自动导入；本次数据已冻结用于对齐验证。

本小样只有7节点/7路段/1个连通分量，全部双向；距离单位为图片像素，播放速度是演示速度。不是任意图像自动识路、正式配送/导航接入或游戏测试，也未操作存档。

## 下载后本机运行

在本目录执行 `python3 start_preview.py`，会自动打开浏览器。不需要安装额外依赖或登录BB。也可以用已有静态HTTP服务打开本目录；不要直接以file://打开，否则浏览器可能拒绝读取graph.json。
