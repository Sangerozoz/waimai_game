# 直接在 Tiled 看图和调整

## 1. 街角_直接编辑.tmj

已改成有明确画布范围的 Tiled 文件，并补上锁定的道路/地面参照；房屋、植物和道具是17个独立图片对象，不是把整个画面压成一张图。

- 选中“房屋树木道具”层，使用“选择对象”工具，直接拖动对象。
- 调整大小时保持纵横比；不要用旋转图片来假装修正三维朝向。
- 道路/地面是供编辑检查的几何底图，不是新生美术或精细铺地，不自动修改原路和导航。
- 这是另存的局部编辑检查稿；原 v1、reference25 和用户文件没有改。此稿尚未接回游戏导出流程。
- 建筑与此路段方向不一致的问题在本稿中仍然保留，不能把“能打开编辑”说成透视已修复。

## 2. 25图总图_手工描线比较稿.tmj

把已有25图拼接参考放在锁定底图层，另给空白的“手工路线”对象层，可先用它体验整图＋手工标路线的方式。它是独立比较稿，不替换现有游戏地图/路网。

本次引用的是既有1600像素宽布局参考，不冒充新生成高清整图；原25图及原拼接文件没有改。需要近景时应另评估正式底图分辨率和接缝。

两个文件都依赖本仓库相邻目录中的现有图片，当前应在这里打开，暂不要只搬走一个TMJ文件。生成记录见 creation-record.json。
