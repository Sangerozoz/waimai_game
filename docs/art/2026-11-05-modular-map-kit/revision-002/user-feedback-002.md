# 用户反馈：树和灯认可，建筑与道路方向不一致

用户原话：“目前来看，树木、路灯我觉得 OK 了，但是房子的角度好像和路网的角度不太一样。我不知道能不能对得上。”

本次认可范围为当前树木和两款路灯视觉，不扩大为精确配准、遮挡或游戏验收。保留这些素材，不因建筑问题重复重画。

当前B01四向仍不通过道路方向适配。根据既有手工地基三点估读，F00两边屏幕角约+14.59/-39.19度，F90约+40.70/-10.11度，F180约+15.63/-39.81度，F270约+40.43/-15.31度。此为手工底点近似值，非精密相机反解；四向不能直接当统一正交机位的可靠库。

原投影世界轴的屏幕斜率约±41.57度，但实际源道路并非全沿世界轴，不能用该值冒充每一段路的方向。下一步应取目标街段源节点，通过同一投影得到该街段切向和垂直方向，再以完整地基和墙体竖线共同约束建筑小样；不是把所有房子强行对齐同一个屏幕角。平移和等比缩放不能改变地基角度，平面旋转不能替代建筑三维转向，禁止拉斜图片或修改原路来掩盖。

当前不扩其余4栋；保留当前原生版本，建筑需形成同一机位/目标朝向的修订小样再验证，不能承诺靠摆放即可对上。
