## 本轮实做

- 将revision-003新原生建筑接进独立街段，复用用户认可的树与两款灯，增加3树/3灯的可编辑摆位和一块可编辑铺装。不是再生图，也不是拿同楼复制充不同建筑。
- 当前7个静态实例：1楼、3树、2单臂灯、1双臂灯；骑手沿已有原路做内存演示。街段全景与近景均为实际Cocos运行截图。
- Tiled位置、正等比缩放、显示/隐藏、组偏移，以及图层顺序和对象index/topdown顺序可导出到预览；当前实际引擎节点与本次导出的7对象顺序、坐标对应。地面多边形同步为原材质铺装，原道路最后覆盖，路网节点/宽度/方向/投影不动。
- 修正了旧预览缩放时围绕地图原点偏移的问题，现在放大仍保留视野中心，不再一放大就把目标建筑推出画面。

## 编辑与导出

本目录的`integration/street.tmj`是**新独立街段候选**；原用户手调`probe.tmj`、旧`revision.tmj`和revision-003全部保留，不重置或反写。

在Tiled保存本候选后，从仓库根目录运行：

```sh
python3 docs/art/2026-11-05-modular-map-kit/revision-004/tiled_street.py export
```

刷新[实际预览](viewer/)即可。`init`只允许首次创建，已有地图拒绝重置。导出只更新本revision的派生viewer，不改tmj；不支持的PNG旋转/镜像/非等比拉伸、透明层和重复对象ID会明确拒绝，不默默导错。动态骑手按地面深度插入静态顺序，仍不是逐像素遮挡系统。

本机未找到Tiled应用，未声称已在Tiled GUI打开/手拖验收；已实际执行此JSON地图的创建和重复导出，并在Cocos读取结果。Tiled几何参考图是旧原路PNG；多边形在编辑器用平面填色显示，在Cocos使用既有铺装纹理。
