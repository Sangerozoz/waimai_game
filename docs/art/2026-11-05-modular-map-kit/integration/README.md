# 单楼四向、树池与路灯隔离接入

`pilot.tmj` 为独立 Tiled 地图，`runtime/assets/` 可供已有 HighCameraCity 查看器的独立副本加载。原 tiled-probe、原 Cocos 源码/构建、道路、骑手路线和存档均不写入。

```sh
python3 docs/art/2026-11-05-modular-map-kit/integration/build_integration.py prepare
python3 docs/art/2026-11-05-modular-map-kit/integration/build_integration.py import
```

prepare 仅用于首次生成，已有 pilot.tmj 时拒绝覆盖；在 Tiled 保存修改后用 import 更新运行数据。原参考道路 PNG 与七张原生素材逐字节复制，不裁切、旋转、镜像、改像素、重采样或合并栅格图。

主图为四栋独立建筑朝向实例、单树和两种单灯。隐藏组合组含两条世界轴方向的三树、三单灯与九双臂灯示例，均为独立可编辑对象。组合默认不导出，以免混入主图；显示对应组后重新 import 即可。对象正数等比缩放与分组偏移可导入，PNG 平面旋转/镜像不支持。

编辑器沿用16px/m、原点(896,896)、62.5°/45°投影；底图只作锁定参考，运行道路仍用原节点/宽度。沿用已扩大地面范围与原骑手，镜头仅改为80投影单位概览。运行遮挡按 sortMap 的投影深度排列，不以 Tiled 手动列表顺序排列。

`calibration.json` 保存手估地面角点和名义尺寸。楼体/树池以左、右相对地面角点中点为地面中心，用两条邻接底边对16×11m（旋转向11×16m）或2.6×2.6m做单一等比尺度拟合。`asset-manifest.json` 同时记录两边独立尺度、残差、实际斜率与目标斜率，不能把这一拟合称为相机通过。路灯以手估杆顶/底点和L01名义7m、L02名义6m杆高设尺度，垫座宽度不被伪称精确配准。

当前树使用 T01-v2，未接入较正视、树干过长的 v1。已见楼体轮廓白色/彩色边缘、独立朝向比例变化；v2树池拟合后的树高仍不能证明与名义6m精确一致。保持原图且如实标候选，待用户看实际效果。静态 SHA/坐标记录只证明数据一致，不证明美术、透明边、镜头、遮挡或游戏验收；未运行阶段游戏测试。
