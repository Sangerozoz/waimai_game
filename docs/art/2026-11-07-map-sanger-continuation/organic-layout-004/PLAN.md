# 非规则城市局部样片实施计划

**目标：**以一张实际新原生检验曲折路网、不等形街坊和沿地形组织的城市画面。写集限定本目录与地图主状态/收据/索引；旧图、旧路网和产品线只读。

1. 核对183项上轮产物和91保护源，另存本轮开始状态；记录用户原话与已实际查看的参考。
2. 生成仅含像素设计坐标的SVG/PNG底稿；核道路端点共享、无异常相交、八个道路围合及实际面积差异。底稿不作为实际描路或米制校准。
3. 通过当前内置image_gen顺序生成一张候选，输入结构/风格/城市组织/密度各有独立角色；保存精确提示词和输入SHA。
4. 将返回原件逐字节复制入本目录，检查尺寸、hash、建筑完整性、道路变化与密度。按实物记录问题，不自动批准或批量扩量。
5. 建立可打开的新图/底稿/旧25总览对比，检查实际显示。先交本张结构与画面，完整矢量描路、Tiled与独立导航待本张审画后另做；不将底稿冒充实测，不跑正式游戏。
6. 更新当前地图状态/报告/预算入口/收据，核91保护源，更新本会话manifest；只备份本地图写集。
