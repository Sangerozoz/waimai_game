# 松本市真实路网复刻样本

用户要求复刻真实地图，认为手绘路网仍太假。本轮已从项目留存的OpenStreetMap XML复制连续选区，不再润饰007手绘布局。008是结构证据版本，0生图请求。

入口：`index.html`（可缩放/拖动、看局部、切换原建筑轮廓与步行线、点道路看源ID）。矢量`roads.svg`；经纬度`roads.geojson`；保留原几何与22类白名单way标签的重建XML子集`source-extract.osm`；几何/标签/裁点`network.json`；来源SHA`source-provenance.json`。XML子集保留完整原节点序列及坐标，但省略所有节点标签（包括门禁）、其他way标签、关系与版本/用户/变更集元数据，不是完整原始OSM副本。完整原XML保持在原项目来源路径。

旧红框中央宽高各半的参考窗口为1661.74×1661.735源投影近似米，面积约2.76137km²，仅作为源数据取样，不冻结新城分区或标定任何生成图。1217条OSM highway记录、1218折线部分、6784源线段；5448原节点身份、91边界裁点。47较高等级、422街道/支路、144服务通道、604非车行记录。原记录可能拆分同一条街，也可能为步行场地边界，不当物理道路数、导航边数或街坊数。

完整保留相交源线段及全部折点，仅窗口边界线性裁切。道路连接依原节点身份；不合并几何交叉。桥、层级、单行、access等白名单标签原值保留，不解释为完整车行权限或转向规则。导航未认证，步行线/场地边界不进入车行交会标记。source-extract.osm故意保留选中way框外节点；GeoJSON与网页只显示窗口部分。

作者核验：Cohen–Sutherland独立对照构建器Liang–Barsky，61908断言通过；最大端点差3.55×10⁻¹⁵源投影单位。XML原坐标与节点顺序、GeoJSON全属性/顶点、SVG每个顶点、网页生成内容及指纹核对通过。真实浏览器10项/3截图、375px页面通过并已关闭；道路点选为DOM合成事件，未声称真实指针点击测试。见verification/。本轮未运行Tiled或游戏。

原始保存时间2026-10-27／28，不是实时现场测绘。数据并不保证完整映射所有通行细节，建筑上下文也不完整。保留源geometry不等于城市分区/可玩性/米制纹理采样与近景清晰度验收。全部原源与用户手调保留，A2/B1/C普通入图与D暂停保持，累计仍7请求/6成功。

独立复核未发现Critical/Important，允许作为真实OSM路网结构参考展示；亲自核对来源SHA、两个原源重复记录、53462源段、导出几何/身份/标签及8002网页顶点。唯一Minor是“原始XML”措辞过宽，作者已按上文收窄并补列省略范围；这次文字修正未另行冒充审查者回审。审查者未亲跑作者61908项或真实浏览器，见INDEPENDENT-REVIEW.md。
