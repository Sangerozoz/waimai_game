## 已确认的范围规则

- 圈内制作街区，取餐、送达及主角/NPC的配送路线全程限制圈内。
- 圈外用绿地、树林、山脉收边，形成可视背景；不制作经营街区或生成配送点。
- 按用户不规则闭合边界保留范围，不自动换成包围矩形；圈内地点如需借道圈外才能到达，应提出具体位置供用户决定，不擅自扩圈。
- 底图出图时尚无圈线；用户现已交回红/蓝/绿分区，解释与近似坐标见上方新入口。仍未裁剪游戏路网、制作街区、派开发、运行游戏测试/构建或操作存档。

## 数据与坐标

原始数据为项目 `delivery-game/assets/resources/map-sample/city.json`。道路、建筑、水域直接从几何数据导出；没有用生图猜测道路、修改原始节点，或把底稿整图作为可玩地图。两图均北向上、坐标单位为米。比例尺、网格与道路共用映射。

[manifest.json](manifest.json)保留每张图的地面坐标范围、像素绘图区、像素/米映射、尺寸、原始数据SHA和图片SHA，供收到圈线后反算边界。图上原始取送点仅供定位，不等同于运行时动态经营点目录。游戏中的地名/店名为项目参考命名，底图不是行政县界。

导出脚本：[render-basemap.py](render-basemap.py)。仅生成本目录的规划图和元数据，不导入游戏运行模块、不访问用户存档。底图包含原始OSM数据的已有归属标记。

今天已认可的页面图片另存于[已确认开发参考](../2026-11-02-approved-ui-reference/README.md)，不是本底图目录。
