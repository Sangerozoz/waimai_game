# 原坐标三维街角资产 v2

2026-11-03。依据[样板规格](../../superpowers/specs/2026-11-03-street-corner-3d-design.md)与[实施计划](../../superpowers/plans/2026-11-03-street-corner-3d.md)制作，目标参考为[用户交回概念](../2026-11-03-sample-fidelity-rework/user-target-v2-concept.png)。这是实际可消费的声明式三维几何资产；没有代填工程运行、最终画风或用户验收。

## 交付

- `scene-design.json`：固定 v1 接口，全部形状已经烘焙为 mesh；建筑为硬边面法线，树冠/人物有机体为平滑法线。顶点以米为单位，按建筑/街景分组和材质合并。
- `manifest.json`：SHA、来源、数量、相机候选、静态检查范围及真实未执行项。
- `build-scene-assets.py`：Python 3 标准库确定性生成器，种子 `20261103`。在仓库根运行 `python3 docs/art/2026-11-03-street-corner-3d/build-scene-assets.py` 只重写本目录两个 JSON；不写原地图。

当前资产为 **174 个分组 mesh、3,354 个作者构件、48,484 个三角形、145,452 个顶点、46种材质**。生成器沿用逐面拆分顶点的合批布局（平滑表面也显式提交法线），因此顶点数为三角形数的三倍。文件 6,966,208 字节；JSON SHA256 为 `c94451f7435125fd6534062b555acf8a61e4ff0e8fea1682bd426d7b5dde102c`。对象数不代表游戏 draw call，最终合批/导入由 Cocos 消费器决定。本轮依据[首版真实工程图](engine-v1.jpg)进行资产修改，具体反馈与边界见[feedback-v1.md](feedback-v1.md)；新资产尚未渲染。

## 制作内容

三栋主体有厚窗框、深色窗洞层、较大玻璃、首层门/把手/台阶、屋顶女儿墙与设备。餐饮楼使用倾斜橙色遮阳棚和室外桌椅/奶白遮阳伞；现代楼使用连续玻璃和窄横梃；商住楼使用挑板与浅阳台。屋顶没有种树。玻璃反射、暖色室内层与木柜台均为不透明几何近似。

街面包含原宽道路、连续人行道/路缘、分缝铺装、路口避让开口、中心虚线及一处斑马线。另有4株通过道路距离筛选的地面树、6段后侧花槽、路灯、长椅、垃圾桶、一辆小汽车和全橙圆灯D车/骑手的静态尺度参照。树冠由多簇小叶团组成，仍属于程序几何造型；它不是已完成的手工植物模型库。

主镜头 `target=[8,7,3]`、`position=[-30,70,105]`、`orthoHeight=31`。**Cocos 的 orthoHeight 是半高**，此值为62m垂直可见跨度。本轮向正面略转以缩窄三栋楼的屏幕横向投影，再拉近取景，减少空铺装边境。静态审算414×798画幅下主体投影范围：水平`[-10.844,13.833]m`、垂直`[-17.065,22.374]m`，处于可见半宽16.083m/半高31m内。manifest 保留首版半高35的次选镜头。静态投影不是渲染验证，实际画幅/缩放仍需开发观察。

## 已执行的静态完整性检查

生成器已经实际运行成功，并检查：源足迹耳切三角形面积与原多边形面积相等（含L形凹角）；顶点/法线有限；索引范围有效；材质引用存在；法线近单位长度；量化后的三角形非退化。硬边法线与绕序精确对齐；平滑有机表面的三个顶点法线均在该面的外朝半球内。box、闭合柱、屋顶/地面棱柱的绕序经静态几何审阅，遮阳布/伞面/细叶有显式双面三角形。所有输出 shape 都是接口支持的 mesh。

接续时修正了三处静态问题：把相机半高63改35并向主体偏移；删除餐饮楼被退台实体埋入的重复下层屋顶设备；对人行道/路缘/分缝做路口几何差集，将原本用于遮盖穿插的抬高沥青圆片降至车行道面。此处只陈述几何修改，不宣称已经看到最终画面。

## 局限与未执行项

本资产任务没有启动游戏、浏览器、渲染器、typecheck、单元/回归测试或存档访问，没有修改业务代码或其他任务文件。`engine-v1.jpg`由PM提供，原样保留，未以AI或图像编辑替换。没有自动下载模型、外部资产或新依赖。source 的文件 SHA 是生成时快照，后续源地图变化需要重新生成。

材质目前为纯色粗糙度/金属度参数；没有手绘贴图、真实透射玻璃、屏幕空间反射或专属着色器。建筑采用独立几何设计，窗格和树叶仍含程序重复；静态汽车与骑手只用于尺度参照，不能等同正式车型/人物资产验收。主光、环境光、阴影、色调映射、抗锯齿与相机取景由 Cocos 工程实现，其实际画面尚未由此任务验证。此包不能证明已经达到参考图，也不替代用户审美验收。
