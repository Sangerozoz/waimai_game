# 小街区画路试验

打开 `画路试验.tmj`。底图已经锁定，选择上面的“路线”对象层，按 P（插入多边形工具），沿道路中心线逐点点击，按 Enter 或右键结束，这样生成的是开放的多边线。不要点回第一个点闭合成填充多边形。每段结束后再画下一段。

先画几条相互连接、含转弯和交叉口的路即可，不必马上描完全部。希望连通的交叉点尽量点在同一位置，必要时放大检查。第一轮可先描中央十字路与上方环路；左下小支路可能独立，不要为追求连通而强接穿楼。完成后按 Command+S 保存这份TMJ并告诉助手；不要改底图的大小、偏移或覆盖原图。

这是新生成的一张试验底图，不是旧图裁片。实际尺寸及来源在 provenance.json。地图坐标就是图片像素坐标，没有再次施加等角投影。路线层初始为空，由用户亲自绘制；自动转路网及寻路尚未完成，不作为本次已验证结果。原游戏、旧路网、旧Tiled和用户布局均未改。
