# 31人肖像候选交付

仅本目录产出。内置 image_gen 原生生成，无CLI/API、无程序绘制、无插值放大；业务/UI公共素材/地图/经济/存档未改。

## 接入入口
- manifest.json：assets键覆盖hero与npc-1..npc-30；file为项目相对路径，rect为左上源像素[x,y,w,h]。
- roster.json：31人候选展示昵称、成年外貌/性格、资源与rect。不覆盖业务名册；前11个昵称借用认可页面展示，后续为制作候选。
- generation-records.json：实际尺寸/模式/alpha/SHA、完整prompt、参考源SHA、原生生成位置、看图结论与问题。
- delivery-integrity.json：31ID、SHA、文件存在、rect边界核验；不是游戏测试或美术验收。

## 服装纠偏
用户补充“个性化、服装造型差异可以大”后，首组和已在生成中的第二组v1均保留为rejected历史，当前manifest仅引用v2。不以v1作服装母版。后续衣服包括工装背心、运动服、针织衫、衬衫、开衫、皮夹克、棒球服等，脸型、年龄感、肤色、发型和少量配饰各有安排。所有图实际看图后归档，未见六格串脸/跨格共体；风格化男性眉眼仍有趋同。

## 尚存候选问题
- 前12名男性偏相似的俊朗眉眼与三分之四视角，虽有脸型/发型/配饰差异，不能宣称无限差异或用户已认可。
- 整队背景与光线相近，部分发顶离上沿较近；脸部尺度有轻微差别。
- 文字身份设定不是逐像素复刻：第29名疤痕位置偏额头，第30名眼镜偏圆；部分发长、肤色、年龄感也有艺术化解释。
- hero基于原身份源重绘近景，棕短发/棕眼/橙反光衣/白内搭保留，但五官细节与身形无法视作严格身份配准。
- 本批全部candidate，不代填usable或用户验收，不报告98%还原率。未运行游戏或改存档。
