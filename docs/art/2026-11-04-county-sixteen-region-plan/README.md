## 放大清晰度：已知限制与生产门槛

16张在相同原生尺寸下，地面线性像素密度较九张约提高1.274～1.358倍（包括重叠差异），不能据数量自动承诺放大高清。当前实际生图原文件均1254×1254，聊天图不是另有高清母版的缩略预览。

16区若仍用1254原图，8m道路仅约7.03～8.22原生像素。维持原A约7.13458投影像素/米的历史细节参考，纯地面需约8707～9030原生方图；留10%画布余量约9674～10033。原A尺度只作细节对比，不是新统一像素残差门槛，也不是用户要求每栋达到旧A相同比例。

现有独立county-region相机配置最小视宽35地图单位。16区1254原图在这种近景下，横向可用原生信息仅约35～36像素；即使只按390显示像素示例，也会放大约11倍。最终画面还取决于实际设备渲染像素、画布大小、裁切与纹理密度，不能只通过改4×4解决。未操作引擎页面或修改相机限制。

下一步先做**单张高清原生输出可行性收口**：明确实际返回尺寸、地图覆盖跨度，以及目标设备/现有近景的像素预算。当前内置调用未暴露显式尺寸参数，提示词请求更大尺寸的既有尝试仍返回1254；未验证4K/8K输出能力。不能默认为已支持、偷偷改用外部API、插值放大、压缩真实地图，或未经说明收紧放大范围后宣称达标。若实际原生能力无法满足，向用户展示具体差距与可选取舍，再确定正式高清交付方法；在此之前不批量生成16张同规格低清图。
