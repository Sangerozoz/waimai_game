## 实际观察及转译

照片可见主干道附近较大的建筑体量、内部更细碎的低层屋顶、小中大地块混合，以及不同庭院/侧院/铺装组织。不是每个街区都用同一种中央草坪＋整齐公寓的组合。此为对照片的观察，不宣称现实楼的具体用途或每栋都独一无二。

新NR-22设计改为多个具有不同组织方式的邻里：细碎窄面宽商住、侧院低层住宅、错落中层街墙、较大围合体量、零散办公/店铺、沿水小院、较疏的大跨度低层。位置按源地块适配，不改原路；大型特殊建筑分散且有来源用地约束，不能简单复制用户图中心地标组合。每个邻里的体块、前后退距、屋顶、入口/院落朝向与疏密要变化，不能只把公寓换颜色。

真实照片只借城市结构层次；用户确认的下载/11/地图效果图.png仍决定绘画风格、材质色彩和自然日光，原结构图仍决定道路/水系/机位。不要继承实拍的阴霾、透视、日式传统地标或全城灰屋顶。
