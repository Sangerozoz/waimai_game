## 美术依据

直接附[用户原参考](../2026-11-03-whole-region-map/references/2026-11-03-user-building-variety.png)作为新图的建筑造型、材质、色彩和日间光照依据。完整来源与角色记录在[reference-contract.json](reference-contract.json)。A-v3、后批和review-001保留历史，不再递归作新图美术母版；源几何图只限定原路、水系、三层边界与已定62.5°/45°机位，其配色、示意楼盒不进入最终画风。

参考里可观察到玻璃塔楼/退台办公体量、曲顶公共建筑、有入口组织的街边商铺、不同高低与立面节奏的住宅；不是所有区重复放同一套地标，也不是把所有住宅改成同款公寓。按实际用地选择形态，保持参考的整体绘画语言；不自行追加整体偏黄、全蓝补色、统一发光窗或灯带。自然阳光和玻璃反射仍按原参考保留。屋顶不种树，地面绿量及已定相机约束保持。

以用户红框完整范围划3×3九大区，蓝框配送范围、绿框城区范围、原路坐标及地图真实尺度不变。九区几何与原道路结构图见[geometry目录](geometry/)。每条相邻边预留共同的真实地面带以便接头，跨边建筑保留整栋参考；几何分界不是最后切楼的ownership线，接缝归属必须看实际图后再定。

旧1056区队列停止，36区静态部署只保留历史。不能先继续生成海量小块再合为9张，也不能把已有小图放大冒充新大区细节。新九区原生美术当前为0张，几何规划图不是美术成图，更不是已完成整县。

## 原生清晰度是实际约束

每区核心约1.108km见方，比旧120m图大很多。几何计算显示，维持A既有约7.13458投影像素/米，需要约1.15万～1.18万像素的方形原图，且这还未计建筑投影与安全边距。当前历史生图的实际返回尺寸为1254×1254，不能据提示词承诺工具会返回4K或更大。

1254原图覆盖整个大区时，8m道路约只有5～6像素，20m建筑约13～16像素；中央NR-22包含692栋源建筑参考，不能同时声称保留旧近景建筑细节。具体原生输出和可读性须在首张大区尝试中如实记录；如无法达到使用要求，应把实际图与取舍交用户判断，不擅自恢复小块队列、缩小县城或通过插值放大掩盖限制。最多16张是上限，不是默认直接加到16；改成16也不能凭空解决原生尺寸限制。
