原图按manifest.plannedOriginal保存，路径目前是约定交回位置；保留原文件并记录实际格式/尺寸/SHA、透明是否真实、视角/身份问题与用户确认。若存在边缘杂色/光晕，单记待处理，未获处理授权不自动改原图。交付可用时由开发唯一集成，顶视车辆pivot以车身中心为起点并与引擎朝向匹配，车辆不等比拉伸，展示图不接地图。

每项状态按待制作→用户已交图→用户接受/待处理→开发接入→待阶段测试分别登记；本包只完成提示词与依赖，不宣称实际产图。不得自动浏览器发送/轮询；不改生产，不测试/渲染。
