## 布局建议

- 城区：社区/水岸、沿街商住和南部生活街区相衔接，以3–6层为主，节点少量稍高楼；具体密度、楼型在实际样板中对照认可首页调整。
- 郊区：以1–3层住宅、院落、小店为主，街区间距更大；沿主路适度集中，与城区平缓过渡。
- 外围：北侧和东侧山林，西侧保留原河谷水系，南侧草地/水岸；不形成可配送街区。
- 样板：推荐绿框内的榕树街食堂与晴川广场周边。现有两处入口之间原始道路参考约424m，可以将道路、店面、住宅、桥/河岸衔接与镜头一起组织；不是新增订单或强制任务。
- 地块内容：样板及后续城区/郊区的剩余地块都要安排建筑、绿地、公园、学校等明确用途，不能留大片未布置空地；正常道路、水域和必要通行空间继续保留。

## 本轮静态盘点结果

- 保持原单行方向、仅使用蓝框内完整原始路段，盘点到3328个道路节点，其中3155个与榕树街食堂起点可往返。
- 原始地点参考目录有14处在蓝框内，14处均可往返。**这不是运行时动态经营目录，也不是游戏只能有14个地址。**
- 蓝框边界有98条穿界原始路段记录，按同侧35m邻近关系聚为79组，其中13组为主路候选口；不是要求增加79个设施或逐口新建道路。
- 蓝框内有11个忽略方向的连通分量，主要分量3229节点，另外10个分量共99节点；另有部分单行支段不能从起点往返。图中标明，尚未修复。
- 既有建筑轮廓按中心盘点：蓝框内1012处、绿框内830处、首块精修范围113处。这是数据库存，不是113张新建筑图片的制作任务。
