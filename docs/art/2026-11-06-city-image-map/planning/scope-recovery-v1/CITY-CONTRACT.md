# 整城总体制作规范 v1（设计提案／能力关卡版）

**当前只准总规核查和一次代表性容量验证。普通区域生图继续暂停，D不恢复。**

## 1. 固定目标，不用图数替代范围
- 总区域约旧25图地图面积1/4；按已有近似红框与同形状缩减，设计参考约1.66×1.66km，而非3张/4张图片的比例。原标注非精密测绘。
- 新设计采用米制规划坐标，和原生像素坐标分开。现有A/B/C尚未建立该映射，覆盖比例未知；不得事后把几个街区任意定义成1.66km来凑面积。
- 保留已认可的画风、颜色、清晰度、建筑/道路视觉比例和A2高密城市核心方向。不能缩楼、窄路、暗缩镜头或插值冒高清来满足范围/图数。
- 红展示、蓝经营城市、绿繁华核心的分区意图保留；新规范的边框仅是可逆设计提案，不覆盖旧边界/业务/存档。

## 2. 总体组织建议，不再从单图倒推城市
- `scope-plan.json`目前给出64个道路围合街坊、81个交口、18条纵横走廊构成的组织起点；这些不是用户指定数量，也不是最终棋盘式路型。
- 数量依据是约1.15×1.08km城市范围内，保留正常路宽、约百余米街坊尺度；不是为了凑64或图数。最终可按校园/公建/公园/地形合并街坊、调整路型，但不能未经说明少掉大半城区。
- 外环承接主要出入口；主干承担跨片区交通；次干分配社区；生活支路接具体街坊。采用旧工程已有宽度档位11/8/5m作为可讨论设计参考，内院约3.6m后续另设计，绝非当前新图已实测米数。
- 结构图保留环路与多条替代路径，不只一个十字和两个回圈；支路必须真接主次干道，路口/单向/不同层级相交语义后续显式导出。
- 工坊/商业/住教/住宅/社区公园组织成片，相邻功能有过渡。高密核心连续街面、商办与住宅前后排；向郊区才逐步增院落/菜畦和自然边缘。蓝内不以大片没设计的草地填空，也不把自然外围密铺住宅。
- 住宅约半按蓝内净可用土地面积后续统计；32个住宅街坊标签不能替代该面积验收。

## 3. 单个街坊与分区必须交什么
每个街坊有编号、用途/密度、道路临界、入口与场地组织；完整楼群/庭院/必要绿地，不是孤楼加一条细通道。公共园区可多街坊联合，记录其真实占用，不重复计数。

每张区域图在生成前必须声明：覆盖的设计范围、应包含的完整街坊、主次道路/出入口、原生像素需求、接头及重叠归属。输入是结构导向，最终须看原始返回图实际包含了什么，不能把“提示词写8街坊”当成实际画齐8街坊。

正式分块先服从街坊和道路/绿地走廊，不切楼。只有共享边口/拓扑/完整街坊是硬关卡，不要求AI逐像素复刻整个结构底稿；小几何变化可在新副本内按真实画面描线，但不能少道路、丢街坊、穿楼补线或改旧区迁就新图。

## 4. 原生容量关卡（本次实际执行）
- 现已实证的1536×1024只证明小样输出，不证明4～6图可覆盖目标城市。
- 本次从总规取4列×2排的8个完整街坊，制作独立结构/尺度导向；以原25画法及获认可A2局部密度为图像参考。不是旧A2放大或D区续产。
- 在同一Hermes/OpenAI API路线只请求一次3824×2144高返回尺寸实验，n1/max_retries0，480秒整体上限。尺寸支持和返回细节必须看实际结果，不能按参数声明成功；不得自动重试或退到小图后称覆盖完成。
- API原始字节/输入/代码/请求/真实尺寸和错误均保留，无本地插值/变形。厂商内部生成分辨率不能仅凭输出尺寸证明，须另看1:1细节。
- 尺寸命中只是第一关。还须独立看8街坊/道路关系是否实际保留、建筑是否因内容太多变成小点、局部是否仍达到获认可样板的阅读水平。
- 本次成图不算新增城市区域，也不提高地图面积完成度；未校准当前三图，不把实验图直接接正式地图。

## 5. 图数预算的处理
4～6张目前只是未被容量证明的PM预算，不是用户指定硬图数。若不能同时覆盖目标并保持可读尺度，须以真实返回结果给明确的原生尺寸/图数取舍，不自动恢复9/16/25或暗自缩城市。

容量表里的道路宽度/62.5度只是敏感性假设，不能据此宣称当前地图实测面积。正式预算应绑定选定设计标尺、实际原生可承载街坊、边带损耗和真实近景，而非“每张图看起来挺大”。

## 6. 关卡与组织
1. 父PM负责完整规范/总量/资源预算，单一版本入口本文件＋scope-plan.json；新规范需独立只读复核。
2. 容量验证只一次，由父执行，保留现有Hermes地图会话做独立审查，不新建或借产品线会话。
3. 总量/尺度和能力证据成立后，才确定具体生产分块并放行代表性相邻区；不能继续从四区候选补格推整城。
4. 分区实际导入同一Tiled候选，原生图和世界坐标偏移只应用一次；图像裁切归属不等于移动区域或再次偏移道路。
5. 真正用本轮新底图做跨区导航；官方Tiled实际渲染与GUI窗口、独立导航与正式游戏分别记录。原图/用户手调不覆盖。
6. 主次道路/片区/街坊覆盖有完整清单，批次写集互斥；实现、几何核查、美术用户验收分层。不以几张图/工具数量/局部到达替代整城验收。

本轮不改原city/游戏UI/经济/订单/存档，不游戏tests/typecheck/回归/FPS，不新开服务，不提交发布。没有足够能力证据时报告限制，不向用户保证下一次一定成功。
