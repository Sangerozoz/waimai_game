## 可编辑范围与坐标

整区位图内的单楼、桌椅和树木**不能独立拖动**；可编辑区域组偏移、道路节点和空白的边界／停靠／独立装饰层，不新增真实经营点或公交玩法。

A区域偏移(0,0)，B原生区域偏移(1472,0)，重叠64px。A取原生x=0..1504，B取x=32..1536，仅无损裁出核心，不拉伸原图；B核心子层额外x=32，所以显示核心起点为全局1504。道路坐标只应用区域组偏移一次，共享节点为(1504,558)。

原请求接头y=600未被A严格保持；实际A中心约556，B根据真实64px窄边带继续，实际约558。此差异已明记，不把原合同说成严格通过。当前道路可见连通，路沿/纹理/草木仍有细小差异，非像素级无缝验收。没有移动或变形原生道路来迁就旧路网。

道路在Tiled中是开放多边线；本次手工按实际图片描线，不是自动识路。路口已经显式分段，共11节点、12路段、1个连通分量。若手调路口，连通端点须重合，不能以穿楼线补连通。

仅调整道路节点后，在本目录运行 `python3 export_roads.py`，只刷新路网及离线页，不回写TMJ。若更改区域偏移，工具会保留修改并明确停止：须重新检查底图核心位置、接头和画布后再导出，不能自动恢复旧摆位。导出后的新改动须重新验证，旧运行记录不套用。
