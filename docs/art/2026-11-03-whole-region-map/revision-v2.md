# 区域A第二版：绿量与建筑形态修订

用户检查v1，明确绿地过多、建筑相似度过高；交回新区域参考，仅提供建筑风格/多样形态及绿量比较，不提供镜头、透视或道路布局。相机仍60–65°区间内62.5°固定俯角、45°方位。新图继续整区一次生成，不回到逐栋生产。

## 上版提示词的问题

上版一方面要求形态变化，另一方面仍把几乎所有楼限定为同一奶油色4–5层公寓、细阳台、橙色雨棚和类似设备屋顶，并附单一双楼图作为细节主参考；模型因此复用同一种楼。又明确将大块空白分配为公共花园、娱乐绿地与庭院，结构底稿本身也用绿色填所有空地，导致绿地过量。

新参考的差异来自用途与体量：板楼/塔式住宅、玻璃办公楼、L/U形围合公共建筑、阶梯退台、弧形顶大体量、低层商铺、院落；同属白灰现代城镇材质，但轮廓、层数、体块、窗带和入口组织不同。不照抄参考中的城市尺度、高楼高度或机位。

## 完整提示词的修正

- 建筑改为至少7类可辨体量/用途组合，住宅不全带商铺、不全带橙篷；玻璃/横窗/石材公共建筑、阶梯体量、少量弧顶、低层商业混合。先轮廓和用途差异，再颜色细节。
- 绿量目标以**本次用户参考×约0.9**为视觉比例，不是v1再减10%，不是减10个百分点；不虚构精确面积测量。减少大公园/草地，改为有内容的街区建筑、小型公共设施、入口硬地与小院，保留克制点状绿化/树池。无屋顶树。
- 新几何底稿中未分配地面用中性灰褐色，不指令填绿；保持原路与接缝控制点。几何盒体只作机位/位置参考，不能作为重复建筑造型模板。新图只附该底稿及用户新参考，不再附单一双公寓母版强化重复。
- 保留固定光照、原路几何、高机位及可见行驶通道，骑手独立。完整区域原生另存v2，保留v1、prompt、源/参考SHA；不自动覆盖已认可预览。

实际绿量与形态是否符合以新图观察和用户反馈为准，不能仅凭提示词声称精确达到10%。本轮无游戏代码/构建/测试/存档操作。

## 实际首轮观察与定向修订

REGION-A-v2已经整区原生生成：建筑差异明显出现，包括阶梯玻璃办公楼、围合公共建筑、弧顶场馆、石材公共门厅、坡顶联排与多种板楼。大片公园/池塘被去掉，但部分院落绿量收得偏多、硬铺装偏强。因此保留v2完整源图/提示词/SHA，再以它为整区编辑目标，仅补回部分院落草地、地面种植和口袋绿地，形成v3；保持已有楼形/原路/镜头，不重新拆栋。v3目标仍是用户参考绿量相对减少约10%，不是按v2继续减。精确比例未测量，不据提示词或颜色阈值代填用户验收。
