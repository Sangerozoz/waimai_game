manifest.json以maps对象键1..5记录真实尺寸、SHA256、来源、名称及建议rect；rect为原生像素[x,y,width,height]，不是已裁切文件。运行680×200建议先取rect再cover，4/5向上对齐保护高楼顶部，其余居中。未改公共manifest或运行代码。

参考为../2026-11-02-approved-ui-reference/04-maps-v1.png。generation-records.json保存提示词及来源路径，旧类别标签已按当前名称规范化并显式说明，非逐字原始请求的类别标签。画面中不含地图名称、价格、锁、卡框或UI。细小车辆牌照/窗格仍可能存在生成纹理，应以最终逻辑尺寸复核；本轮未执行运行接入或游戏测试。
