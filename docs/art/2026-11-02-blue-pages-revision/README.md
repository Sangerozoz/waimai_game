## 已统一的交互和边界

- 普通首页底栏为骑手/车辆/抢单/地图/账单；打开某页后，**仅当前tab**的图标和文字一起变为关闭×。点该×回默认首页，其他tab仍可切换。订单大厅为中间橙圆显示×；其他管理页的橙圆仍显示抢单。
- 完整头像/地址/经验/金币/体力/评价/骑手1/2只放首页；骑手/车辆/地图/账单仅顶部标题和金币；订单大厅标题、金币和体力。骑手卡自己的等级与主角经验属于卡片内容，继续保留。
- 外部骑手页显示“升级骑手”；车辆选择和车辆升级在配置车辆内页。主角仍靠亲送经验成长，NPC金币升级沿用原数值。删除额度说明和延后生效说明仅是界面删减，不擅自改变相关机制。
- 车辆沿原双列卡片，不改为单列。所有车型默认展示，地图未解锁的显示“未解锁”并禁购，不隐藏卡片。没有单独“已拥有”页签；每张卡仍保留拥有数。
- 地图沿五个地区分别一张全宽图片卡片；不是一张世界地图。当前县城不收费，其余解锁费用500/1500/4000/10000。只把卡片信息简化，经营资格仍按正式V1判断。
- 只修用户明确内容和出图错误。此前擅改的单列车辆v2已作废，连续世界地图v2/v3已被澄清覆盖；这些仅留历史，不能给开发当目标。
