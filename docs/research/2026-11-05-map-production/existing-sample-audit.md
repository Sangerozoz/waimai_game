# 现有高机位样板复用核查

仅源码/清单核查，非新画面验收或游戏测试。无新增图片、采购、代码修改。

- 既有4181/high-camera-city/入口HTTP 200，供用户回看曾认可版本。
- HighCameraCity.ts的ground()按原roads节点和width独立绘制道路；两幅地块PNG独立叠放。因此此样板没有整区图决定道路的结构依赖。
- 地块1254原生、约40像素/投影单位、单幅宽约31.3投影单位，比25区约1.12–1.18的名义密度高约34倍。这个比例是局部素材尺度比较，不是证明整县可用；实际屏幕显示密度要结合视口与设备。
- 两幅含庭院/树池的完整地块为既有素材，不是可分离楼体库。临街边拟合后仍有约1.20/2.23投影单位的后角偏差，不支持精确填满任意异形地块。
- 骑手代码仅接受两点路线、两方向素材；非全县路由与八向接入。ground()将地面合为最长3072纹理，不能直接覆盖全县近景。
- 决策：可复用原路绘制/投影、局部清晰完整地块、既有素材及入口；不批准将两地块复制铺县、不保证任意地块适配。
- 零新增预算下优先验证：使用现有两地块，选择原路中不同方向/形状的另一处合适街区，先离线几何检查能否不旋转/不拉伸地放置、入口朝向正确且不侵入道路；不适配就记失败条件，不生成新素材。该验证尚未实施，也不等于量产可行。其目的是判断可复用范围，而非再造一个漂亮孤立街角。

## 第二位置离线筛查结果

已运行 [检查脚本](reuse-probe/check.py)，[逐候选结果](reuse-probe/result.json)。使用两块地块人工标注的实际边界候选，保持原大小/方向，只作平移；搜索蓝框内原8m宽道路、长至少30m、方向差不超过3度且离原样板80m外的线段中点。对其周边原路面作平面相交/距离计算。

- 找到16个候选位置，其中6个按标注边界未侵入原道路，10个与附近原道路相交。
- 最优候选为原路149288129-0第2段，中点约(-1664.235,335.540)，相对原方向差0.322度；标注边界至最近车行路面约1.63m。
- 仅为局部可放置性筛查，非全县覆盖率，也不是完整复用验收：边界为人工估读；尚未检查源楼/水体/POI冲突、入口接入、投影遮挡或实际画面。即使这6处全能放，也只有两种完整地块图，无法证明满足全县差异性。

结论：有证据说明旧素材在相近朝向的局部位置可平移复用；没有证据支持用现有素材填满全县。不能再把这个局部成功升级成整县生产方案。零预算且时间紧的前提下，完整目标仍缺大量适配素材；应先向用户明确这一缺口，不能擅自降低其多样性要求或继续无限试做。
